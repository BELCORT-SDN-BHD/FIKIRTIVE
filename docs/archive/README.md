# docs/archive/

历史场地文档，只读参考，不构成范围或批准。这里的每一件都曾是某一场的工作面：`MASTERPLAN.md` 的施工总表、`northstar/` 与 `strategy/` 的推演、`research/` 的竞品调研、`review/` 与 `audits-2026-h1/` 的一次性审计、`design/` 的旧设计与 route-b 路线稿、`design-qa-2026-09/` 的设计走查记录与截图、`gstack-qa-2026-07/` 的本地 QA 报告。它们记录当时看到什么、当时怎么想，不代表今天的产品方向、优先级或任何已批准的决定。

引用规矩：现行权威在 `docs/INDEX.md` 的前三节（`docs/BLUEPRINT.md`、`docs/specs/`、`docs/adr/`、`docs/runbooks/`、`docs/ops/` 等）。要主张「现在是这样」，请用 live Git、当前代码、数据库与行为测试证明，不能引这里的文档当作依据。

路径说明：归档时保持了原有的相对层级（`docs/history/` → `docs/archive/history/`，依此类推），归档区内部文档之间的互引仍写着搬动前的旧路径；把 `docs/` 换成 `docs/archive/` 即可对上，个别仍留在原位的文件见 `docs/INDEX.md`。
