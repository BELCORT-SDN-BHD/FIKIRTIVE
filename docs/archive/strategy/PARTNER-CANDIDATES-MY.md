## 我的判断:最值得优先谈的 2–3 家

FIKIRTIVE 要的是三件一次拿——**信任背书 + 一批数字活跃的同类商家(F&B/预订/礼品,IG/FB+WhatsApp)+ 订单回执数据接口(证据层)**,红线是**永不白标、商家数据主权保住**。据此排序:

**第一优先:Revenue Monster。** 它是唯一同时满足三条的:F&B/零售商户基数、SME 主攻方向、以及候选里**最完整的 Open API**(payments + loyalty/会员 + stores + 交易数据),正是"点亮阶段证据层"的理想数据来源;它的商户本身就在做 loyalty/会员,天然是"数字活跃"的同类商家。唯一要小心的是它自带 social media 管理产品——用**公开共卖**框定,恰好落在你们"永不白标"的红线内侧。

**第二优先:Curlec by Razorpay。** 它是**唯一有正式、可自助加入的合作伙伴计划(马来西亚 Service Partner 转介)**,谈判摩擦最低、有现成佣金机制;Razorpay 的 API-first 基因意味着交易 webhook/数据接口成熟;品牌本身就是背书。它高速抢 SME、要提交易量和留存——你们的营销 OS 正是它想给商户的增值钩子。**最容易真正开上会的一家。**

**第三优先(二选一):**
- **senangPay** —— 若你要的是**最大批 SME 商户 + 心智背书**,且它当前正处开放结盟期;但请先向对方核实"活跃商户"真实口径(官网 16 万 vs 报道 3,500 差距过大)。
- **Fiuu** —— 若你更看重**数据规模作证据层**(TPV US$66 亿、SEA 最大交易底座之一),有明确 channel/reseller 邮箱;代价是决策偏企业级、SME 亲密度低、速度慢。

**建议打法:** 先并行敲 Revenue Monster(数据+同类商家最契合)和 Curlec(合作门最好进),用 senangPay 做规模备胎;iPay88/eGHL 因已并入 NTT DATA,背书虽硬但决策慢,列为第二波;Stripe 只做技术集成、不作分发伙伴。

**数据可信度备注:** senangPay 商户口径、Revenue Monster 商户数(最新公开数据停在 2022–2023)、eGHL/iPay88 的当前活跃商户数,公开信息都偏旧或口径不清,进入实质谈判前需要对方给最新真实数字——这几处我已如实标注,未做外推。

## 判断:最值得 FIKIRTIVE 优先谈的 2-3 家

FIKIRTIVE 要一次拿三样——**① 信任背书 ② 一批数字活跃的同类商家(F&B/预订/礼品,IG/FB+WhatsApp)③ 订单回执数据接口(证据层)**;红线:**永不白标(公开共卖可以)、商家数据主权保住**。据此排序:

**🥇 第一优先:StoreHub** — 商家画像的精准命中。它的 20,000+ 马来西亚商家正是 F&B/零售/服务、IG/FB/WhatsApp 经营的那群人;而且它是**马来西亚首个官方对接 LHDN e-Invoice 的 POS,发票/退款实时自动提交** = FIKIRTIVE 想要的"订单回执证据层"天然就在这条管道里(记账软件只有事后发票,POS 才有实时订单回执)。已做过 RHB 银行公开联名,证明它接受"共卖不白标"的合作形态。三样里它一次给到②和③,①靠它 SEA 头部 POS 的地位。**唯一注意:** 它是 POS 不是记账软件,但对 FIKIRTIVE 的目标恰恰更好。

**🥈 第二优先:Bukku** — 数据接口 + 意愿的最佳组合。**开放且有文档的 REST API(600 req/min)**是清单里最好接的证据层;云原生、Peppol accredited SP、用"永久免费 e-Invoice"猛拉数字化微型商家(客群年轻对路);小团队增长饥渴、已有 Partner Program = 最容易约到能拍板的人。弱点:仅约 3 万商家,背书分量不如 SQL/AutoCount。三样里它强在②(数字原生商家)和③(开放 API),①中等。

**🥉 第三优先(二选一,走"规模+背书"路线):AutoCount 或 SQL Account** — 当 FIKIRTIVE 需要"体量级信任背书 + 最广触达"时谈这两家(240k / 270k+ 商家,均有 API 与庞大 dealer/channel 渠道可公开共卖)。**建议先谈 AutoCount**:API 平台更现代、有 OneSales/POS 更贴 F&B 零售、dealer 招募更开放;SQL 体量最大但渠道政策保守(每 10 万人口 1 家 partner)、桌面基因、谈判周期最长,作为"背书王牌"留作后手。两家的共同短板:动作慢、渠道重,数字原生度不如 StoreHub/Bukku。

**一句话打法建议:** 先用 **StoreHub(拿画像对的商家 + 订单回执数据)** 和 **Bukku(拿开放 API + 数字原生微商家)** 跑通产品与证据层,再拿这两家的成绩去敲 **AutoCount/SQL** 换规模级背书。**Financio(by ABSS)** 作为"文化最友好的暖场备胎"——它已在大量做银行公开联名,最好敲门,但属上市集团子公司、决策慢,适合并行接触不占主线。

**数据诚实声明:** ABSS/Financio 的"400,000"是区域口径且含桌面老资产,非马来西亚净活跃数;Financio 单独用户数、Million/Deskera 的马来西亚商家数均**未查到公开可信来源,标为未知,未编造**。MDEC 官方 Peppol SP 全名单在 PDF 附件内([mdec.my/national-einvoicing/peppol-service-providers](https://www.mdec.my/national-einvoicing/peppol-service-providers)),如需逐家核对建议直接下载该 PDF。

# 判断:哪 2–3 个最值得 FIKIRTIVE 优先谈

FIKIRTIVE 要一次拿三样:①信任背书 ②一批数字活跃同类商家(F&B/预订/礼品、IG/FB+WhatsApp)③订单回执数据接口。没有单一伙伴同时给满三样,最优是**"一协会(信任+名单)+ 一电信/平台(渠道+数据)"组合**。我的优先级:

**第 1 顺位 — PRESMA(+ MRCA F&B division 作第二 F&B 触点)**
最精准命中目标画像:3,500–4,000 家高度同质的餐饮商家,社群紧密、背书强,且会员正被人手/成本痛点逼着找提效工具 —— 需求现成。协会只出"信任+名单",不碰数据主权,**红线最安全**;订单回执由 FIKIRTIVE 自己的产品补。这是最快能拿到"一批同类 F&B 商家名单触达"的路径。MRCA 的 F&B division(Secret Recipe/连锁品牌)是天然的第二触点。

**第 2 顺位 — CelcomDigi Business(MY5G SME Digital Workshop)**
落地最快的分发管道:全国巡回 workshop 是**现成的联名研讨会/路演渠道**,电信品牌给背书,co-sell 不白标(红线安全),而且它的 partner 生态已含 TikTok Shop、SME Corp、MATRADE —— 一插进去就同时接上"数字活跃卖家(经 TikTok Shop)+官方背书(经 SME Corp)"两条线。是把三样东西串起来的枢纽。

**第 3 顺位(二选一,看阶段):**
- **要规模与信任天花板 → TM/Unifi Business**:400,000 MSME + 600 地推顾问 + 政府 50% 补贴 bundle,是触达面最大、且能用补贴降低商家试用门槛的渠道。
- **要数字活跃 F&B/礼品卖家 + 数据 → TikTok Shop Malaysia**:画像最贴(短视频/IG 式经营),但**白标/数据主权红线风险最高**,只做公开共卖、边界写死,别碰深度数据接口的独家绑定。

**关于 SME Corp**:信任杠杆最大(官方金字招牌)、惯例签 MoU,但节奏慢,更适合当"背书 + 规模"的中长期支柱,而非首谈落地。

**一句话组合建议**:先谈 PRESMA 拿"F&B 同类商家名单 + 社群背书",同期切入 CelcomDigi MY5G workshop 拿"现成联名分发渠道 + 电信背书 + 生态跳板",两条腿同时跑;订单回执数据接口靠 FIKIRTIVE 自有产品闭环,不依赖伙伴让渡数据主权。
