## 1. 产品定位一句话 + 定价模型

**一句话:** invideo AI = 「一句话(或一条 URL、一张产品图)→ 成品营销视频」的 agentic 视频工厂;core = **v4 agent / Agent One**,单条 prompt 自动做完 脚本→选素材→配音→字幕→配乐→转场→多格式导出,号称一条视频背后做 **500+ 个微决策**,最长可生成 30 分钟成片。2026 年演进成「AI 视频操作系统」——底层聚合 **200+ 生成模型**(Sora 2、Veo 3.1、Kling 3.0、Seedance 2.0、Nano Banana Pro、ElevenLabs music 等),上层是一堆营销专用 workflow。用户数 25M+ / 190 国(2025-10 官方口径)。

**定价模型(核心机制,这个是确定的):**
- **credits = 平台内货币**,用于「创建内容 / 跑生成模型 / AI 功能」;**导出/下载不耗 credits**(这点反直觉,是它的卖点)。
- **不同模型吃不同 credits**:便宜的 Kling 2.6 Standard ~0.5 credit,贵的 Veo 3.1 4K 10+ credits;公式 ≈ credits/秒 × 时长,受分辨率/输入质量/是否生成音频影响。加 **AI Twin/Actor(真人或虚拟出镜)额外 +20 credits/分钟**。
- **额度不滚存**:月度 credits 到期清零;单独买的加油包(top-up)12 个月过期、且随订阅终止而失效。
- **「credit trap」痛点(多评测点名):** 把 AI minutes / iStock 下载 / voiceover 分钟 / voice-clone 名额 拆成**互不通用的独立池**,一个池耗尽另一个还满着,逼你提前升级。

**档位(⚠️ 数字跨源分歧大,当近似):** Free($0,带水印+周额度) / **Plus ~$25/mo(年付~$20)** / **Max ~$60/mo(年付~$48,含 4K)** / **Generative ~$120/mo(年付~$100,打包 Sora 2+Veo 3.1)** / **Elite ~$900/mo(高存储高额度)** / Team & Enterprise(SSO/SCIM/SOC2/GDPR)。credits/月各源说法从 Plus 10~75、Max 40~390、Generative 100~800 不等 —— **具体额度未核实**,founder 若要精确数字需登录官网实时查。参考锚点:「1 分钟生成视频 ≈ 7 credits」(单一源,未核实)。

## 3. SMB / SEA 视角(马来西亚/东南亚 SMB 真会用 vs 企业虚胖)

**SEA SMB 真会用(高价值、低门槛):**
- **Money Shot / 产品图→广告**:马来 SMB 卖家(Shopee/Lazada/TikTok Shop 主力)最痛的就是没摄影预算 + 产品/logo 被 AI 拍歪。「4-8 张图→保真商业片」直击痛点,是**杀手级**。
- **URL/图→短视频 + 多格式一键导**:TikTok/Reels/IG 三尺寸一次出,对人手 1-2 人的店主是刚需。
- **50+ 语言 + voice translation**:东南亚多语(马来/英/中/泰/印尼/越)是天然场景,一片翻多市场。
- **对话式 Magic Box**:非技术店主打字改片,不碰时间轴 —— 对齐易管理。
- **Templates 10,000+**:低创意门槛快出货。

**企业虚胖(SEA SMB 基本用不上,别抄):**
- **Elite $900/mo、Team $999/mo、SSO/SCIM/SOC2/GDPR/dedicated support**:纯企业/agency 向,SMB 无感。
- **Pro Avatar(需 30 分钟素材)、多品牌 Brand Kit、Figma 式多人协作**:团队功能,单店主用不到。
- **VFX House(relight/inpainting/虚拟制片)**:创意工作室级,SMB 过度。
- **前沿模型堆料(200+ / Sora 2 Pro / Veo 3.1 4K)**:SMB 只需「够用且便宜」,一堆模型选择反而是认知负担 + 烧 credits 的坑。

**⚠️ 定价对 SEA 的硬伤:** 全 USD 计价 + credit-trap 拆池不滚存,对价格敏感的马来 SMB 摩擦大。**FIKIRTIVE 若做本币计价 + 简单不拆池的额度,天然差异化。**

## 5. 值得偷的 feature 机制(具体、聪明、FIKIRTIVE 该借鉴)

1. **Money Shot 的「产品隔离 → 3D-aware 表征 → 场景合成」保真管线。** 上传图后先把产品从背景抠出、建一个「3D 感知的形状+纹理表征」,再放进 preset 场景里生成运镜/打光/剪辑 —— **不是让大模型直接想象产品,而是先锁定产品资产再合成周边**。这正是「零文本幻觉 + logo 不变形」的关键。FIKIRTIVE 若做产品广告,这个「先锁资产、后生成环境」的分层是核心可借。

2. **「导出不耗 credits,只有生成耗」的计费心智。** 把钱花在「造」而不是「取」,用户导出无心理负担、敢多导多试 —— 降低试错摩擦。对齐 FIKIRTIVE「video 近成本卖、margin 在别处」。

3. **preset(11 种商业风格)+ 一句话 prompt 的「选风格再描述」双输入。** 用户不用会写复杂 prompt,先点一个「High-End Luxury / Food Porn / Reviewer」把 80% 视觉基调定死,剩下用一句话微调 —— **把 prompt 工程降维成选择题**。极对齐 founder 易管理(可读的风格开关)。

4. **对话式精修(Magic Box)取代时间轴。** 「第 3 镜换咖啡馆」「配乐换爵士」——非技术用户零学习成本改片。这是 Otto 全操控在视频上的直接范式。

5. **一次生成 → 多格式自动裁切导出。** 一条内容自动出 9:16/1:1/16:9,底层是同一素材的智能重构图,不是简单缩放 —— SEA 多平台分发的高频刚需,低成本高感知价值。

## 6. 易管理视角(对齐 founder 第 3 优先级:file-system 风格,可读文件+简单开关)

invideo 让非技术用户驾驭复杂功能的聪明做法,和 founder 哲学部分吻合、部分相悖:

**吻合(值得借鉴):**
- **preset = 可读的「风格开关」**:11 个命名清晰的商业风格,用户点一下就懂,不需要懂参数。**这就是 file-system 式的「可读+简单开关」在创意维度的体现。**
- **Autopilot 三档(Basic/Pro/Ultra)= 单一复杂度旋钮**:把「AI 自动多少 / 我控多少」压成一个三档开关,而不是几十个设置 —— 复杂度收敛成一个可读选择。
- **对话式编辑 = 无需学习界面**:打字即改,没有时间轴/图层认知负担。
- **一句话 prompt + 上传图 = 极简输入契约**:输入面越窄,越好管理。

**相悖(FIKIRTIVE 可反向差异化):**
- **credit-trap 拆池 + 不滚存 + 全 USD**:这恰恰是**难管理**——用户搞不清哪个池还剩多少、钱花哪去了。FIKIRTIVE「单一 credit 池 + 本币 + reserve/settle 透明账本」正是更易管理的反面教材式机会。
- **200+ 模型选择**:表面强大,实则给用户认知负担。founder 若坚持「精选 2-3 模型 + 简单开关」,反而更对齐易管理。

**给 FIKIRTIVE 的一句话:** invideo 在「创意输入端」的易管理做得聪明(preset/对话/单旋钮 —— 该偷);但在「计费/额度端」难管理(拆池/不滚存/外币 —— 正好是 FIKIRTIVE 用透明单池 + 本币 + 可读账本 反超的口子)。
