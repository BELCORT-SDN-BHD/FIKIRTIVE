# Zoho FEATURE 深研 —— 给 FIKIRTIVE 的候选映射

范围:Zoho One(套件)/ Zoho CRM(核心对象+自动化)/ Zoho Marketing Plus(跨渠道)/ Zia AI + Zia Agents(数字员工 marketplace)/ Bigin(SMB 简版)/ SEA 渗透。全部功能名保留英文 + 中文注释。不确定处标「未核实」。

---

## 1. 产品定位一句话 + 定价模型

**一句话**:Zoho 是「一个价钱买下整间公司需要的 50+ 款 SaaS」的一体化套件之王 —— 从 CRM 到会计到 HR 到营销全自研、全打通,现在再叠一层自研 LLM(Zia)+ 可当「数字员工」部署的 AI Agent 市场。这正是 FIKIRTIVE「全家桶 + Otto 全操控」愿景在市场上最接近、最成熟的对标物。

**定价模型(2025-2026,均为每用户/月,美元)**:

| 产品 | 入门档 | 顶配档 | 计价逻辑 |
|---|---|---|---|
| **Zoho One**(套件) | $37/员工/月(All-Employee,年付,须全体持牌) | $90/用户/月(Flexible,只买需要的席位) | 席位制;"$1/天/员工"是招牌话术 |
| **Zoho CRM** | Standard $14 → Professional $23 → Enterprise $40 → **Ultimate $52**(年付) | 免费档:3 用户 | 席位 × 编辑档;功能按档解锁 |
| **Bigin**(微企 CRM) | $7/用户/月起 | — | 席位 + Toppings 按需加购 |
| **Marketing Plus** | 分档订阅(按用户 + email/用量) | — | 席位 + 用量(email 量、webinar 等)混合 |
| **Zia Agents** | Agent Store 预建 agent 可部署;用量另计(未核实具体计价) | Agent Studio 自建 | 「数字员工」按部署 + 用量,细节未公开核实 |

关键机制:**席位 + 用量混合**。WhatsApp、email 量、Zia 数据富集、API credits 都是「基础配额 + 超额买 credit」。这跟 FIKIRTIVE 的 credit-ledger 经济学(USD-pegged、reserve/settle)是同一套心智,只是 Zoho 把它藏在席位价背后。来源:[Zoho One pricing](https://www.zoho.com/one/pricing/)、[Zoho CRM pricing](https://www.zoho.com/crm/zohocrm-pricing.html)、[Bigin compare](https://www.bigin.com/compare-zohocrm-editions.html)。

## 2. 功能总清单(按子领域;每条:名称 / 做什么 / 价位档)

### A. Zoho One 套件广度(50+ app;这是「全家桶」的物理证据)
按类别(来源:[Zenatta 46-apps](https://zenatta.com/zoho-one-all-46-apps/)):

- **Sales & Marketing**:CRM(客户数据+销售自动化)、SalesIQ(访客追踪+live chat)、Campaigns(email 营销/drip)、Marketing Automation(web 追踪+journey)、Social(多平台排期+lead form 同步)、LandingPage(落地页+UTM)。
- **Email & Collaboration**:Mail、Cliq(内部 IM/频道/通话)、Notebook(笔记)、Assist(远程支持)。
- **Finance & Ops**:Books(会计)、Expense(报销/收据扫描)、Payroll(薪资合规)、Commerce(电商)、Zakya(POS)。
- **HR**:People(员工档案/PTO/onboarding)、Recruit(招聘 pipeline)、Learn(LMS 培训)。
- **Project & Work**:Projects(甘特+工时)、Sprints(敏捷)、Tables(与 CRM 同步的工作流表)。
- **Analytics & BI**:Analytics(仪表盘+预测)、DataPrep(数据清洗)、PageSense(热图+A/B)。
- **Docs & Content**:Writer / Sheet / Show(Office 套件)、WorkDrive(云盘)、Forms(表单)、Sign(电子签)。
- **其它**:Vault(密码管理)、Sites(建站)、Backstage(活动/票务)、Flow(类 Zapier 自动化)、Creator(low-code 建 app)、Lens(AR 远程排障)。

> 对 FIKIRTIVE 的意义:Zoho 用「一个后台 provision 全部 app + SSO + 统一 admin」解决海量 feature 的组织问题——**不是把功能塞进一个 app,而是很多小 app + 一层统一入口/权限/账单**。这跟 founder 的「file-system 风格、可读文件+简单开关」直觉高度一致。

### B. Zoho CRM 核心对象与自动化(来源:[CRM 全功能对比](https://www.zoho.com/crm/complete-feature-list.html))
- **核心对象**:Leads / Contacts / Accounts / Deals(全付费档);Sales Forecasting 含区域预测(Enterprise+)。
- **Workflows**(工作流规则):Free 10 条/模块 → Ultimate 150 条/模块、每条最多 10 条件。
- **Blueprint**(流程蓝图,拖拽式强制销售流程状态机):Professional 3 个 → Ultimate 100 个。**这是 Zoho 的招牌「流程即状态机」机制**。
- **Macros**(一键批量动作):Professional+。
- **Cadences**(多步跟进序列:email/task/call/WhatsApp):Professional(20/模块)→ Ultimate(70/模块,最多 90 步跟进)。
- **CommandCenter / Journey Builder**(跨部门客户旅程编排,no-code/low-code 信号配置):Professional 起(1 条活跃 journey)→ Enterprise/Ultimate 5 条、每天 20 万记录移动。来源:[Journey orchestration](https://www.zoho.com/crm/process-management/journey-orchestration.html)。
- **Canvas**(no-code CRM 界面设计器,重画 List/Detail/Form/Print 视图):Standard 起,50 视图/模块 + 100 canvas rules/模块。来源:[Canvas](https://www.zoho.com/canvas/)。
- **Omnichannel**:email(IMAP/POP3/Gmail API,Standard+)、telephony、social、live chat、web forms、**WhatsApp Business(需 credit,Professional+)**,全部汇入单一 timeline。SalesInbox = email 优先级排序。
- **Analytics**:Custom Reports(Standard 100 → Professional+ 无限);Anomaly Detector(Enterprise 起 10 trends)。
- **Customization**:Custom Modules(Standard 10 → Ultimate 500)、Custom Fields(Standard 10 → Ent/Ultimate 300-500/模块)。
- **Developer**:API credits(Free 5,000 → Ultimate 无限)、Functions(Standard 起,serverless 代码)。

### C. Zia AI(CRM 内置助理,22 项能力,分 5 族;来源:[Zia](https://www.zoho.com/crm/zia/)、[AI features overview](https://www.zoho.com/crm/ai-features-in-zoho-crm.html))
- **Predictions**:Lead/Deal Scoring、Prediction Assistant(自定义预测字段,展示预测所用输入数据 + 准确率)、Churn Prediction(Ultimate)。
- **Automation**:Workflow/Macro Suggestion(Zia 建议自动化)、Best Time to Contact、Anomaly。
- **Communications**:Email Sentiment、Email/Call analysis、Best-time。
- **Analytics**:Ask Zia(自然语言问答→自动出图表,如"top 5 reps by closed-won this month")、Analytical component suggestions(cohorts/quadrants/anomaly detectors 建议)。
- **Generative & Conversational**:自动起草 email/proposal/report;OpenAI-powered 对话(可选)。
- **底层**:2025-07 起自研 **Zia LLM**(1.3B / 2.6B / 7B 参数,Zoho 自托管,数据隐私内建)。来源:[Zoho launches Zia LLM (BusinessWire)](https://www.businesswire.com/news/home/20250717118204/en/Zoho-Launches-Zia-LLM-and-Deepens-AI-Portfolio-with-Prebuilt-Agents-Custom-Agent-Builder-MCP-and-Marketplace)。

### D. Zia Agents / Digital Employees(← founder 点名要挖的「数字员工」打法;来源:[Zoho Agents](https://www.zoho.com/agents/)、[agentic AI in sales](https://www.zoho.com/crm/zia/agentic-ai.html))
- **Agent Store**:100+ 预建 agent,跨 60+ app。命名 agent 例:Sales Development Representative Agent、Email Responder、Payroll Sentiment、Refund Tracker、Meeting Scheduler Agent。
- **Agent Studio**:no-code / 全 prompt-based(可选 low-code)自建 agent;开箱即用 **700+ actions** 跨 Zoho 产品。
- **部署方式三种**:① 自主运行 ② 按钮点击 / 规则触发 ③ 在客户对话中被召唤。
- **Digital Employee(核心概念)**:部署时可把 agent「provision 成一名数字员工」——**沿用组织里既有的 user access permissions(不另造权限体系)**;admin 可做 behavioral audit + performance/impact 分析。
- **Zoho MCP Server**:让外部 LLM(ChatGPT / Claude)接上 Zoho 的 API / 数据模型 / actions。
- 时间线:2025-07 发布 → 2025 底 GA;截至 2026-05 Marketplace 已上 25+ 可部署 agent(不同页面口径 25+ vs 100+,以官方 Agents 页 100+ 为准但**两个口径均标注为存疑**)。

### E. Marketing Plus(跨渠道营销 OS;来源:[Marketing Plus features](https://www.zoho.com/marketingplus/features.html))
- **Planning**:Marketing Calendar(自定义营销日历)、Campaign Management(多渠道活动统一工作区)、Task/To-dos(按状态/活动/负责人分组)、**Budget Management(设预算+记支出+按活动类型/地区/目标分类+仪表盘监控)**。
- **Channels**:Email & SMS(拖拽 builder、240+ 模板、A/B、触发器)、Social(监听 hashtag/关键词 + 管 7 大平台 + lead ads)、Webinars(投票/实时 Q&A)、Events(注册/票务/建站主题)、Surveys(25+ 主题)、Presentations(100+ 模板+实时协作)。
- **Collaboration & Brand**:Content Creation(版本控制 + Zia AI 文档助理)、Collateral/Brand asset 管理(集中存 + 角色/团队分享 + 密码保护)、**Brand Management(一屏管渠道/活动/用户/权限)**、Campaign Discussions(评论/@/附件)。
- **Analytics**:**Unified Marketing Analytics(跨渠道混合数据 + 按渠道/活动算 ROI)**、Marketing-Sales Integration(营销花费↔CRM 销售)、Paid Marketing Insights、Website Performance(热图/滚动图/A/B)。
- 另含:Landing Pages、Marketing Automation(个性化 journey)、Conversational Marketing(live chat + AI chatbot)。

### F. Bigin(微企 CRM,简单到「不用培训」;来源:[Bigin vs CRM](https://zenatta.com/crm-vs-bigin-choosing-the-right-zoho-solution/))
- 单一可视化 pipeline 为中心;Team Pipelines(多产品线各一条 pipeline);**Toppings**(按需加购的附加功能 + 第三方集成,不塞进核心)。$7/用户/月起。定位:微企、个体户、「不想花三周 onboarding」的人。

## 3. SMB / SEA 视角(马来西亚/东南亚 SMB 真会用 vs 企业虚胖)

**真会用(SEA-SMB 命中)**:
- **Bigin 式单 pipeline 简版 CRM** —— SEA 微企的甜点,零培训。
- **WhatsApp 深度整合**(汇入 CRM timeline、Cadences 里可发 WhatsApp)—— 东南亚 WhatsApp 是主渠道,这是刚需不是 nice-to-have。
- **Social(管 FB/IG/多平台排期 + lead ads)+ Email/SMS** —— SMB 营销全在这几个渠道。
- **Budget Management + Unified Marketing ROI** —— 老板要看「钱花哪、哪个渠道值」,直觉可懂。
- **预建 Agent(Email Responder、Meeting Scheduler、SDR)** —— 「请个不用发薪水的员工」对缺人的 SMB 极有说服力。
- **本地化红利**:Zoho × Cradle Fund 给马来西亚 4,400 家初创 USD 1000 万软件 credit;Zoho CRM 2024 全球 25 万+ 企业、YoY ~30%、SMB 占 >50%。来源:[Zoho CRM stats](https://electroiq.com/stats/zoho-crm-statistics/)、[SEA CRM market](https://www.mordorintelligence.com/industry-reports/south-east-asia-crm-market)。

**企业虚胖(SEA-SMB 用不到 / 反成负担)**:
- **Blueprint 100 个 / Journey Builder 5 条 / CommandCenter 跨部门编排** —— 是「大公司多部门流程」的能力,微企一条 pipeline 就够,配起来反而劝退。
- **50+ app 全套** —— 广度是卖点也是诅咒:SMB 用不到 Payroll 合规、Vault、Backstage、Lens 等;「一个价买全部」听着爽,实际只碰 5-6 个。
- **Ultimate 档的高级 AI/ML、data prep、专属基础设施** —— 企业向。
- **API credits / Functions / Creator low-code** —— 需要技术团队,SMB 无人配置。

> 核心张力:Zoho 靠**广度**赢企业心智,但 SMB 的真实体验是**在 50 个 app 里迷路**。这正是 FIKIRTIVE 的机会窗口——**用 Otto 一个入口收敛广度**,不让用户面对 app 目录。

## 5. 值得偷的 feature 机制(具体、可落地)

1. **Digital Employee = 复用现有权限,不造新权限体系**。Zia agent 部署成「数字员工」时,直接继承组织里 human user 的 access permissions,并可做 behavioral audit。→ 对 FIKIRTIVE:Otto 的每个动作应在**用户自己的权限边界内**执行 + 可审计,这同时命中 founder 的「安全」第一优先级和「易管理」第三优先级。这是最该偷的一条。

2. **Ask Zia:自然语言→自动出图表**。用户打「top 5 reps by closed-won this month」直接得到可视化。→ FIKIRTIVE 的 analytics/效果营销区应支持自然语言问数据,而非让用户配 dashboard。低成本、高感知。

3. **Blueprint 的「流程即拖拽状态机」但反过来用**。Zoho 让人画状态机(太复杂)。FIKIRTIVE 可偷「用可读的状态/步骤表达一个流程」这个**呈现方式**,但让 **Otto 生成 + 用户只读/开关**——把 Zoho 的强大机制降维成 founder 要的「可读文件 + 简单开关」。

4. **Unified Marketing Analytics + Budget:一屏「钱花哪 / 哪个渠道 ROI 最高」**。跨渠道混合数据 + 按活动分类预算。→ 效果营销支柱的默认首屏,老板视角直觉可懂。

5. **Toppings:核心保持极简,附加功能按需加购**。Bigin 不把高级功能塞进核心,而是让用户在需要时「加一个 topping」。→ 对齐 FIKIRTIVE「简单开关」——默认极简,能力以可开关模块渐进解锁,而非一次性堆满界面。

## 6. 易管理视角(对齐 founder 第 3 优先级:file-system 风格,可读文件 + 简单开关)

Zoho 让非技术用户管理复杂功能的聪明做法:

- **统一 admin panel + SSO + 集中 provision**:50+ app 但一个后台开关谁能用什么。这是 Zoho「不失易用」的关键——**复杂度藏在统一控制台后**。契合 FIKIRTIVE 想要的「一处可读、简单开关」。
- **按编辑档渐进解锁**:功能不是全给,而是随 Standard→Ultimate 分层出现,低档界面更干净。→ 借鉴:默认档极简,高级能力默认隐藏。
- **No-code 全 prompt 的 Agent Studio**:自建数字员工不用写代码,纯自然语言描述 + 700 现成 actions。→ 这正是 founder「非技术用户也能管」的样板:配置 = 打字,不是编程。
- **Digital Employee 的 audit / impact 分析**:把 AI 员工当员工管——看它做了什么、表现如何。→ FIKIRTIVE 若给 Otto 一个「它替我做了这些(可读日志 + 一键开关某类自主动作)」的面板,直接命中「非常容易管理 by 自己」。
- **反面教训**:Zoho 的 Blueprint / Canvas / Creator / CommandCenter 虽强,但都是「给用户一套建造工具」——对 SMB 是负担。FIKIRTIVE 的差异化恰恰是**把「建造」交给 Otto,把「可读 + 开关」留给用户**。这是「易管理」的更高阶实现,别抄 Zoho 的 builder 心智。
