## Vision

### 10x Check
Artlio 的 12 个月 10x 形态：任何重度创作者的「实体资产银行」。@Maya 是可导出、可版本化、可交易的资产包（参考图组 + prompt 词 + 负面约束 + LoRA 指针，签名打包）。创作者交换/出售角色包、场景包、配方包——如同今天交换 LoRA 与 ComfyUI 工作流，但带完整产权链与版本史。产品从工具变生态：用户资产库越厚，迁移成本越高；模型方言每多一种，中立层增值一分。结构层的终局不是功能，是网络。

### Platonic Ideal
你坐下来，带着一个想法。输入一句话，@ 出你的演员阵容、场景、产品——工作台已经认识它们全部。它在你浪费第一次生成之前告诉你缺什么。每个产出自动归位、回链、可对比。三小时后你有成片，而且你的资产库比开始时更厚。工具随每个项目增值。用户的感受："我的工作室记得一切。"

### Strategic Positioning（D2 批准）
模型中立的实体资产层——"references 的瑞士"。模型层（Kling 3.0 character locking、Vidu Multi-Entity）正在吞掉单模型一致性；Artlio 锚定模型层永远不做的事：跨模型、跨镜头、跨版本的实体资产层。per-model adapter 是该定位的工程兑现。@mention 实体语法目前无竞品。
