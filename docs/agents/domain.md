# Domain docs

FIKIRTIVE is a monorepo with one shared product domain.

Before exploring or making domain decisions:

- Read root `CONTEXT.md`.
- Read relevant ADRs under `docs/adr/`.
- Use the terminology defined in `CONTEXT.md`.
- Surface conflicts with an existing ADR instead of silently overriding it.

If a required term is missing, note the gap for `domain-modeling`. Do not create
additional context files unless the domain structure is explicitly changed.
