## 1. 产品定位一句话 + 定价模型

**一句话定位**:Pippit 是 CapCut/ByteDance 出品的「电商 + 社媒营销内容生成 agent」——把一个产品链接/文件/素材,一站式变成可直发 TikTok/IG/FB 及 TikTok Shop 的短视频、UGC 广告、海报和图片,并自带 avatar、排期发布和分析。核心杀手锏是 **Link-to-Video(链接直接成片)** 和 **自训 avatar**。

**定价模型**:credits 制(积分),月/年订阅 + 按需加购积分包。

存疑点(重要,如实呈现):**官方 /pricing 页当前渲染出来的是三档付费**(Starter $120/mo、Plus $360/mo、Pro $1,800/mo,含 2,100 / 6,700 / 35,500 credits,年付 8 折),但**所有 2026 独立评测一致报的是「Free + Starter」两档结构**,Starter = $36.25/mo(月付)或 $24.17/mo(年付 $289.99),含 1,800 credits/mo。两者数字差一个量级。可能原因:官方页在做地区/币种/A-B 分流渲染,或近期改版,或 WebFetch 抓到了某个本地化变体。**未核实哪个是马来西亚实际看到的价**——founder 若要用作 benchmark,需实机开 pippit.ai/pricing(马来 IP)确认。下文功能的价位归属以「Free vs 付费」二分为准,避开这个数字冲突。

- **Free**:150 credits/周(周一刷新),约 2 分钟视频 + 75 张图/周;带水印;3 个 photo avatar;可发 3 个社媒平台;Agent Mode 每周 1 次;不需信用卡。
- **付费(Starter/全解锁)**:1,800 credits/mo(年付合 21,600/年);去水印;无限 photo avatar + 1 个 custom video avatar 免积分;custom voice;批量;fast generation;高级 AI 模型;4K upscale。
- **加购积分包**:100 credits = $0.70;500 = $3.50;3,000 = $21(高量更划算)。
- **关键积分消耗率**(评测实测,供 FIKIRTIVE 定价对标):Link-to-Video 30–60 credits/条;avatar 视频 40–80 credits(或约 2 credits/秒);图片生成 ~2 credits/张;去背景 ~1 credit/张;Agent Mode 固定 150 credits/次。
- **模型菜单**(官方首页在列,验证 ByteDance 全家桶策略):Veo 3.1、Sora 2、Seedream 5.0 Lite、Dreamina Seedance 2.0、Nano Banana Pro——多模型混挂、不同档位给不同速度/模型。

## 2. 功能总清单(按子领域穷举)

### A. 内容摄取与「链接→成片」闭环
- **Link-to-Video(链接转视频)** — 贴一个产品页/网站 URL,自动抓取产品**描述、规格、标题、图片**;用户可改产品名、勾选保留/删除哪些图、补传本地/云素材;选平台(TikTok/IG/FB)+ 时长(15/30/45/60s);系统给 **4 个基于 TikTok 热门趋势的脚本** 供选或自写;配 avatar 口播(Smart Match 自动选或手动选音色/口音);出片 3–4 分钟。付费去水印。→ **这是整个产品的核心闭环**。
- **Poster / 多格式同源产出** — 同一个链接除视频外,还产出**高清海报、网站 banner、Pinterest pin、IG 轮播图**,风格与视频一致。
- **Reference Video(参考视频复刻)** — 上传一条对标爆款,AI 模仿其**叙事结构与美学**再创作。
- **文件/素材摄取** — 除 URL 外接受 text prompt、图片、视频、文档作为输入。

### B. 视频生成
- **AI Video Agent(视频 agent,自动发布)** — 多轮对话式,输入 link/file/media/prompt/reference,选模型(Lite/Agent/Veo 3.1/Sora 2),生成后可编辑,**可直发或排期到 TikTok/IG/FB**;宣称会「学习你受众最活跃的时段,在你睡觉/开会时自动挑高互动时段发」。
- **Image-to-Video(图生视频)** — 静图转动态视频。
- **AI Video Generator** — prompt 直出营销/社媒视频。
- **Product Showcase(产品展示视频)** — avatar 拿着/演示产品,可自定义动作细节;单条最多约 5 分钟生成。
- **UGC Content Creator** — 生成 UGC 风格达人带货内容。
- **Video Translation(视频翻译)/ AI Dubbing(配音)** — 视频转多语言 + 配音/口播换语言,面向全球分发。

### C. 图片与设计
- **AI Image Generator** — 文生图,多风格(复古/波普/极简/卡通等)。
- **AI Design Generator** — 海报、社媒广告、版式设计。
- **AI Background Generator + Background Removal** — 换背景/去背景。
- **Layout-to-Design(版式转设计)** — 照片版式→成品设计。
- **Image Resizer / Upscale(4K)/ 图像增强(调色、降噪)**。
- **Batch Generation(批量生成)** — 一次多张、混合/融合图片;批量编辑多图。

### D. Avatar 与口播
- **Digital Avatars(数字人库)** — 600+ 现成 avatar,支持 28 种语言、约 869 种语音选项(评测数,官页写 30+ 语言/80+~600+ 不等,**数量口径未统一**)。
- **Custom Avatar / Video-to-Avatar(自训 avatar)** — 拖入自拍视频(MP4/MOV,720p 或 4K,<1GB)+ **必须录一段读指定脚本的授权同意视频**;约 **60 分钟** 训练出「数字分身」,复刻语音/表情/动作。付费档含 1 个免积分 custom video avatar。
- **Photo Avatar / Custom Avatar(照片转 avatar)** — 上传一张照片,6–10 分钟出动态 avatar,可调表情/颜色/风格。Free 3 个,付费无限。
- **AI Talking Photo(会说话的照片)** — 静图 + 语音/音乐变动态口播。
- **AI Voice Generator / Voice Cloning** — 自定义语音,可上传录音克隆或选库内多语种音色。

### E. 发布、排期、分析
- **Content Publisher(内容发布器)** — 一键发到 TikTok / IG / FB / TikTok Shop。
- **Schedule Posting(排期发布)** — 免费排期,跨平台管理发布时间;Agent 可按受众活跃时段自动排。
- **Social Media Analytics(社媒分析面板)** — 汇总 FB/TikTok/IG 的 views/互动/分享/评论到一处;评测称为基础级。

### F. A/B 测试(创意实验)
- **多变体创意 + 内建 A/B** — AI 快速生成多条视频/图/文案变体,**内建分析对比哪个变体转化/互动/ROI 最高**,号称「无需外部工具做 A/B」;可测不同 presenter/语气/语言组合。
- 存疑:官方 video-agent 工具页**未提** A/B/变体;A/B 主要出现在 pippit.ai 的 resource/blog 营销文与部分评测里。**产品内是否有正式独立的 A/B 实验模块,还是「生成多条 + 看分析」的组合叙事,未核实**——需实机确认。

### G. 素材库与模板
- **Assets Management(资产库)** — 组织管理生成的素材;Free 档评测提到约 500GB 存储。
- **Templates(模板库)** — 大量 Product UGC / UGC demo / 客户评价 / 开箱 / 教程 模板;拖拽编辑、文字叠层、可换配色。
- **内建编辑器(CapCut 引擎)** — 特效、音频分层、时序、自动多语言字幕、语音克隆、去背景、视频防抖等专业剪辑能力直接内嵌。

### H. Agent Mode(总控)
- **Agent Mode / Creative Agent** — 一句 prompt 从想法到成片全自动;固定 150 credits/次,Free 每周 1 次。评测评价:**产出偏「通用/模板感」,需大改脚本,12 条测试里评分最低(5/10)**——即最激进的「全自动」是其最弱环。

### I. 电商集成
- **Shopify 原生集成** — 连店铺,自动从 listing 生成产品视频。
- **TikTok Shop 原生集成** — 直接给电商卖家生成产品展示视频并直发。
- **Amazon listing** — 评测用 Amazon listing 链接跑 Link-to-Video(经 URL 摄取,非官方深度集成)。

## 3. SMB / SEA 视角(马来西亚/东南亚 SMB 真会用 vs 企业虚胖)

**SEA SMB 真会用(高相关)**:
- **Link-to-Video + TikTok Shop 直发** — 东南亚 TikTok Shop 是主战场,「贴 listing 链接→3 分钟出带货短视频→直发店铺」精准命中卖家日更痛点。**这是对 FIKIRTIVE 最有杀伤/最值得对标的一簇**。
- **UGC/达人风模板 + avatar 口播** — SEA 达人营销成本高,AI avatar 顶替真人出镜、多语言(马来语/英语/中文/泰/印尼语)口播,SMB 会真用。
- **Video Translation / Dubbing** — 多语言市场刚需(一条素材铺马来/英/华三语)。
- **一条链接同出海报+banner+轮播图** — 一人运营的小店最爱「一次产出全套」。
- **Free 档 150 credits/周** — 低门槛试水,符合 SMB「先白嫖」心态;但评测称 2–3 条就耗尽,是明确的付费漏斗。

**企业虚胖 / SEA SMB 大概率不碰(标注)**:
- **Agent Mode 全自动** — 产出通用、需大改,SMB 反而更信任「半自动 + 自己微调」;华而不实。
- **多模型菜单(Veo 3.1/Sora 2/Seedream/Seedance/Nano Banana)** — 对 SMB 是选择过载,他们分不清也不关心用哪个模型,只要「出片好看」;这是给 power user/内容工作室的。
- **社媒分析面板** — 基础级,SMB 通常直接看 TikTok/Meta 原生后台,第三方汇总的黏性存疑。
- **4K upscale / 专业剪辑深水区** — SMB 用不到 4K,够发就行。
- **缺协作 / 无 SOC 2** — 评测明确指出,这是**企业采购的硬伤**,但对 SEA 单人/小店 SMB **无所谓**——反而说明 Pippit 定位就是 SMB,不是企业;FIKIRTIVE 同赛道不必追企业合规虚胖。

## 5. 值得偷的 feature 机制(具体、可借鉴)

1. **「一个链接,多格式同源产出」** — Link-to-Video 不只出视频,同时吐海报/banner/Pinterest pin/IG 轮播,**全部风格一致**。机制精髓:一次内容理解(产品语义+视觉)驱动多渠道适配渲染。FIKIRTIVE 可做「一次生成,全渠道成套」——SMB 一人运营最爱,且天然抬高单次生成的感知价值(利于你的 credit 定价)。

2. **URL 摄取 → 可编辑中间态 → 再生成** 的三段式,而非黑箱一键。抓完产品信息后**先让用户改名/勾图/删图/补料再生成**。这个「可干预的中间态」既提升成片质量,又给了用户掌控感——直接对齐 founder「易管理」优先级。比 Agent Mode 的黑箱一键靠谱得多(Pippit 自己也证明黑箱那条最弱)。

3. **「4 个基于当前 TikTok 热门趋势的脚本」预置选项** — 不是空白 prompt,而是把「趋势」封装成可选脚本骨架。机制:降低创意门槛 + 蹭平台算法红利。FIKIRTIVE 可做「Otto 给你 3–4 个当下 SEA 热门脚本框架供选」,而非让 SMB 对着空框发呆。

4. **自训 avatar 的「强制授权同意视频」流** — 把肖像合规做成产品内的一步必经流程(读指定脚本录一段)。既是法律护栏又是信任信号。**直接是 founder 安全优先级的样板**:可读、可审计、fail-closed。

5. **积分消耗率按 feature 分档且透明**(Link-to-Video 30–60、avatar 2/s、图 ~2、Agent 固定 150)。机制:让「贵的功能贵得有道理」,用户对花费有预期。契合你 credit 引擎(USD-pegged、reserve/settle)+ founder「花钱前先问」——可把每个 feature 的预估消耗在触发前明示(你 canvas 已有 cost-confirm,可推广到全线)。

## 6. 易管理视角(对齐 founder 第 3 优先级:非技术用户管理复杂功能)

Pippit 做对的「让小白管复杂功能」的聪明处,及对 FIKIRTIVE 的启示:

- **模板即配置** — 大量命名清晰的模板(「UGC 开箱」「产品 demo」「客户评价」)把「复杂参数组合」封装成一个可选卡片。非技术用户选模板 = 选好了一整套参数。**启示**:FIKIRTIVE 可把常见营销任务做成「可读的模板文件 + 简单开关」(正是你 skill framework 的 file-system 风格),而不是让用户调旋钮。
- **对话式 agent 兜底,但保留可编辑中间态** — 复杂功能用自然语言驱动(Video/Image Agent 多轮对话),但每步产出都能手动改。**启示**:Otto 全操控 + 每步可干预,别做纯黑箱。
- **Smart Match 自动选(音色/avatar/时段)+ 可手动覆盖** — 默认智能、进阶可控的双层。**启示**:「Otto 替你选,但你能改」是易管理与掌控感的平衡点。
- **平台/时长做成有限枚举**(TikTok/IG/FB;15/30/45/60s)而非自由输入。**启示**:把高频选择收敛成几个按钮,减少 SMB 决策负担。
- **透明的积分预算** — 每个动作花多少积分可预期。**启示**:契合你「可读文件+简单开关」哲学——花费也应可读可预期。

**Pippit 在易管理上的短板(反面教训)**:Agent Mode 太黑箱→产出通用→用户反而要花更多力气改脚本,「一键」变「一键+大改」。**启示**:自动化的边界要诚实,别把「全自动」当核心卖点,半自动+可控对 SEA SMB 信任度更高,也更符合 founder「易管理」的真意(可控 > 魔法)。
