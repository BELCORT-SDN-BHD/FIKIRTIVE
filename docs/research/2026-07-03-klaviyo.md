## 1. 产品定位一句话 + 定价模型

**定位一句话:** Klaviyo 已从"电商邮件营销工具"升级为自称 **"AI-first B2C CRM"** —— Marketing(邮件/SMS/Push/WhatsApp)+ Analytics + Service 三大件,底层共用一个内建 CDP(Klaviyo Data Platform),2025–2026 全力押注 AI Agents("Autonomous B2C CRM")。([klaviyo.com/platform](https://www.klaviyo.com/platform), [B2C CRM 发布](https://www.klaviyo.com/newsroom/b2c-crm-announcement))

**定价模型(他们怎么收钱)——核心:按 active profiles(可触达联系人总数)收月费,再层层加 add-on:**

- **主计费轴 = active profiles**,不是发送量、不是功能。2025-02 起改为:账户里所有可触达联系人都计费,不管当月有没有发过 —— 直接导致大量老客户账单跳涨(例:2 万联系人只发 8 千人,账单从 $150 → $375/月)。([omnisend 定价拆解](https://www.omnisend.com/blog/klaviyo-pricing/), [retainful](https://www.retainful.com/blog/klaviyo-pricing))
- **Free**:250 profiles / 500 封邮件/月 / 150 SMS credits,含 Customer Hub、基础报表、Marketing Agent。([klaviyo.com/pricing](https://www.klaviyo.com/pricing))
- **Email 计划**:$20/月(500 profiles)→ $30(1k)→ $60(2.5k)→ $100(5k)→ $150(10k)→ $720(50k)→ $1,380(100k)→ 约 $2,300(250k)。**所有档位功能完全一样,涨价纯粹因为名单变大**。涨档有 25% 涨幅上限保护。([omnisend](https://www.omnisend.com/blog/klaviyo-pricing/))
- **SMS = 信用点数包**:$15/月 1,250 credits 起;每条消耗的 credits 按国家不同(美国 1 credit/条,爱尔兰 9 credits/条);美国约 $0.009/credit。WhatsApp 消息用**同一套 credits** 计费。([firstpier](https://www.firstpier.com/resources/sms-klaviyo-pricing), [WhatsApp billing 帮助文档](https://help.klaviyo.com/hc/en-us/articles/40116442241179))
- **Add-on 单独收费**(这是他们扩大 ARPU 的打法):
  - **Reviews**(评价):≤50 订单/月免费,$25/月@250 订单 → 最高 $20,000/月@100 万订单——按**店铺订单量**计费。([retainful](https://www.retainful.com/blog/klaviyo-pricing))
  - **Marketing Analytics**:$100/月起(@13,500 profiles)。
  - **Advanced KDP(CDP 加强版)**:$500/月起(@100k profiles);与 Marketing Analytics 互斥、二选一。([Klaviyo 帮助中心/多来源](https://help.klaviyo.com/hc/en-us/articles/115000976672))
  - **Customer Hub**:$30/月起(@10k profiles),必须已有付费 Email 计划。([Shopify 博客](https://www.shopify.com/blog/what-is-klaviyo))
  - **Helpdesk**(客服工作台):常规价 $264/月,新品期 30% 折扣。([charleagency](https://www.charleagency.com/articles/klaviyo-pricing/))
  - **Customer Agent(AI 客服)**:**按解决的对话数计费** —— 标准 $75/月含 75 对话($50 促销价),首 50 对话免费试;另一来源称 $200/月 + 超量 $0.70/对话(两来源数字不一致,未核实)。([charleagency](https://www.charleagency.com/articles/klaviyo-pricing/), [retainful](https://www.retainful.com/blog/klaviyo-pricing))
  - **Marketing Agent**:不单独收费,捆绑在所有付费 Email 档里。
- **企业档**:月消费超 $10k 自动转 Klaviyo One,整单加 20% 附加费(第三方说法,未核实)。([omnisend](https://www.omnisend.com/blog/klaviyo-pricing/))

**一句话总结商业模式:名单规模收底租(profiles)+ 消息按量(credits)+ 每个新产品线单独开一条计费轴(订单量 / profiles / 对话数)。**

## 3. SMB 视角(马来西亚/东南亚)

**马来西亚/SEA SMB 真会用的:**
- Flows 预建配方(弃购/欢迎/购后/挽回)——这是 Klaviyo 的"data → automated revenue"精髓,SMB 装完就赚钱。
- 基础分群 + predictive CLV/churn(它把 data science 变成人人可用的筛选条件)。
- 表单弹窗 + 优惠券自动挂车(拉新闭环)。
- Benchmarks 同行对标(SMB 老板最爱"我跟同行比怎么样")。
- Free → $20 → $30 的入门段。

**对 SEA 是硬伤 / 用不上的:**
- **SMS 在马来西亚/新加坡根本不能发**——Klaviyo SMS 仅限美、加、英、澳、新西兰、爱尔兰 + 部分欧洲。"Email + SMS"双引擎在 SEA 只剩一半。([SMS 可用国家](https://help.klaviyo.com/hc/en-us/articles/4402914866843))
- WhatsApp(SEA 真正的王者渠道)刚到 **paid private beta**,且按西方 credits 体系计费——SEA 本地玩家(如各类 WhatsApp BSP)在这条渠道上远更成熟。
- **没有 Shopee / Lazada / TikTok Shop 集成**——350+ 集成全是欧美栈(Shopify/Woo/BigCommerce)。SEA SMB 的订单大头在 marketplace,Klaviyo 吃不到那部分数据。
- 邮件文化弱:SEA 消费者主用 WhatsApp/社媒,邮件打开率生态天然低,Klaviyo 的核心渠道在 SEA 打折。
- 定价 USD 计价 + active-profile 模型:名单一大账单陡涨($150→$375 的案例),对马币收入的 SMB 很痛。([omnisend](https://www.omnisend.com/blog/klaviyo-pricing/))

**企业级虚胖(SMB 基本不会买):**
- Advanced KDP($500/月起,数仓同步/custom objects)——纯中大型企业配置。
- Marketing Analytics add-on($100/月起)、Helpdesk($264/月)、Klaviyo One(>$10k/月 + 20% 附加费,未核实)。
- Reviews 高档位(按订单量最高 $20k/月)。
- 多语言/多店铺 syndication、RCS(SEA 运营商支持存疑,未核实)。

**普遍抱怨**(Trustpilot/评测汇总):账单突涨、10k–25k profiles 段"账单为什么翻三倍"、小店为用不到的功能买单。([retainful](https://www.retainful.com/blog/klaviyo-pricing), [omnisend review](https://www.omnisend.com/blog/klaviyo-review-pricing-features/))

## 4. FIKIRTIVE 候选映射(仅候选,决定权在创始人)

| Templates + Email/SMS AI 文案 | **创作区**(生成)+ **资产区**(品牌模板库) | FIKIRTIVE 创作区已强;缺的是"营销消息模板库 + 品牌资产绑定"这层 |
| Forms / Pop-ups(拉新表单) | **存疑** | 前提是客户有自己的网站可嵌 widget;SEA SMB 很多只有 marketplace 店 + 社媒,无自有站。若做,归 CRM 区的"名单增长"入口 |
| Reviews(请评/展示/AI 情感) | **存疑 / 建议不要**(整套);其中"AI 回复评价"可归 **自动回复区** | 完整 Reviews 需站内 widget + 订单量计费引擎,重;但"自动回复 Google/Shopee 评价"是 SEA SMB 的真实痛点,轻得多 |
| Reporting + Benchmarks 同行对标 | **分析区** | Benchmarks 是强粘性功能,但需要跨租户匿名数据池,早期租户量不够(先做行业公开基准替代?) |
| CDP / Advanced KDP(数仓同步、custom objects) | **建议不要** | 企业级虚胖;FIKIRTIVE 的 CRM 区内建统一档案即可,不需要暴露"CDP"概念 |
| Customer Hub(店内客户门户) | **建议不要** | 依赖自有站 + Shopify 深度数据;SEA SMB 场景弱 |
| Helpdesk + Customer Agent(AI 客服) | **自动回复区** | Klaviyo 按对话数收费($0.70/对话级别)验证了"AI 客服按结果计费"模型;FIKIRTIVE 自动回复区已在此方向,可参考其 retail skills 清单(订单查询/退换/物流)与 Agent Guidance(语气+升级人工规则) |
| Product recommendations / Next Best Product | **存疑** | 需要商品目录 + 订单数据;若客户主营 marketplace,目录数据难拿 |
| Shopify 等电商集成(目录/订单/行为事件) | **CRM 区**(数据源) | SEA 版等价物 = Shopee/Lazada/TikTok Shop/WhatsApp Business 数据接入——这是 Klaviyo 覆盖不了的空位,也是 FIKIRTIVE CRM 区能否成立的关键数据源 |
| Portfolio 多账号管理(跨账号克隆资产/全局报表/集中账单) | **Agency 楼层** | 与 Agency 楼层需求几乎一比一对应;"克隆表单+分群+campaign 到多账号"是 agency 效率刚需 |
| Coupon 自动挂车(表单→优惠券→结账自动应用) | **存疑**(依赖电商平台 API) | 机制聪明,但依赖平台优惠券 API;Shopee/TikTok Shop 有 voucher API 的话可复刻(未核实) |

## 5. 他们的 AI/agent 打法 vs Otto-operates-100% 的差异化空间

**Klaviyo 的打法(三层):**
1. **嵌入式 AI(40+ 工具)**:每个功能里塞一个 AI 开关(subject line、send time、表单时机、分群生成)。不收额外费,用来抬产品价值感。
2. **具名 Agents 单独货币化**:Marketing Agent(捆绑付费档)、Customer Agent(**按对话数收费**——AI 按结果计费的先例)、Composer(private beta,prompt→整套 campaign)。([2026-06 发布](https://www.businesswire.com/news/home/20260630493754/en/Klaviyo-Launches-AI-Agents-that-Work-Together-to-Drive-Revenue-for-Consumer-Brands))
3. **叙事 = "Autonomous B2C CRM"**:两个 agent 共读写同一实时 profile,营销↔客服互相喂数据。

**与 Otto 的本质差异 / FIKIRTIVE 的空间:**
- **边界**:Klaviyo 的 agents 只能操作 Klaviyo 自己那几个产品(邮件/短信/客服),碰不到广告投放、社媒运营、内容生产的全链路。Otto 的定位是**操作全部 districts 的一个雇员**(创作→排期→投放→CRM→客服→分析),这是 Klaviyo 结构上做不到的(它没有广告和内容资产这些"楼")。
- **形态**:Klaviyo = N 个各管一摊的 copilot,各自计费轴;FIKIRTIVE 宪法 = 每个区都是真实可手动操作的工具 **且** Otto 能 100% 操作 —— "一个超级员工"vs"一堆功能内置助手"是可直接讲给 SMB 听的差异。
- **透明度**:Composer 是黑盒生成(prompt 进、campaign 出);Otto 的 skill 文件体系(可读文件+开关)对"非常容易管理 by 自己"的创始人诉求是差异点。
- **定价启示**:Customer Agent 按对话收费证明 SMB 接受"AI 按结果计费";Marketing Agent 捆绑证明"agent 当增值不当门票"也成立。两种都有市场验证,FIKIRTIVE 可选(不替创始人决定)。
- **风险提示**:Klaviyo 一年发 75+ 新功能、agents 迭代极快([9 大 AI 功能](https://www.klaviyo.com/blog/klaviyo-ai-for-autonomous-marketing-and-customer-service));若它补上 WhatsApp GA + SEA 渠道,SEA 空窗会收窄。FIKIRTIVE 的护城河更应压在 marketplace 数据 + 全楼层操作,而非单点功能。

## 6. 值得偷的设计(他们做得特别聪明的机制)

1. **预建自动化配方库(60+ flow recipes)** —— 自动化不是空白画布,是"装了就能跑"的配方:默认触发器+默认文案+默认分支,SMB 一键启用。与 Otto 的 skill 文件体系同构:FIKIRTIVE 的 lifecycle 自动化若做成"可读配方文件 + 开关",既符合创始人的 file-system 管理哲学,又复刻了 Klaviyo 最强的 activation 路径。([flows 页](https://www.klaviyo.com/features/flows))
2. **预测值 = profile 上的一等字段,不是报表** —— CLV/churn/下次购买日直接出现在分群条件和 flow 触发器里("predicted next order date"可以当触发器!)。数据科学被产品化成"人人会用的筛选项",这是"data → automated revenue"的核心机关。([AI 功能页](https://www.klaviyo.com/features/artificial-intelligence))
3. **Peer Benchmarks(100 家匿名同行对标 + Excellent/Good/Fair/Poor + 改进指引)** —— 把跨租户数据变成粘性功能和心理钩子;SMB 老板看一眼就懂。FIKIRTIVE 租户到量后,SEA 本地行业的对标数据是 Klaviyo 给不了的。([peer groups 文档](https://help.klaviyo.com/hc/en-us/articles/360050180151))
4. **Agent 写回共享档案的数据飞轮** —— Customer Agent 每解决一次对话就把偏好/意图写回 profile,营销侧立刻可用。对应 FIKIRTIVE:Otto 在任何一个区的操作结果都应写回品牌记忆/CRM 档案,让"跨区复利"成为架构级特性。([2026-06 发布](https://www.businesswire.com/news/home/20260630493754/en/Klaviyo-Launches-AI-Agents-that-Work-Together-to-Drive-Revenue-for-Consumer-Brands))
5. **表单→优惠券→结账自动应用的闭环** + **功能不锁档、只按规模计费(配 25% 涨幅上限)** —— 前者把"拉新→首单"缝成一条线;后者让 SMB 从 Free 无摩擦长大(虽然也是他们被骂最多的点——账单随名单膨胀,FIKIRTIVE 定价可借鉴"全功能开放"但避开"存量计费"的怨气)。([coupon 文档](https://help.klaviyo.com/hc/en-us/articles/6038674938523), [omnisend](https://www.omnisend.com/blog/klaviyo-pricing/))
