# Jasper 深研报告 —— 超级员工 agent 产品化的镜子

> 研究焦点:Jasper 从"AI 写作工具"转型为"agentic marketing platform",其**用户自建/管理 agent 的 UI 与治理**、以及**品牌语音资产模型**,正是 FIKIRTIVE 把 Otto 产品化时要照的镜子。全部 feature 名保留英文+中文注释。绝不编造,不确定处已标"未核实"。

---

## 1. 产品定位一句话 + 定价模型

**定位:** Jasper = 面向**企业营销团队**的 agentic marketing platform(agentic 营销平台)—— 把品牌治理(brand governance)+ 一整套专用营销 AI Agent + no-code 工作流构建器打包,核心卖点是"AI that knows your brand"(懂你品牌的 AI)。2025 年做了 $88M 营收、10 万+ 活跃客户、平台年内 7600 万次生成(76M generations)。

**定价模型 = 席位订阅 + 用量信用(credits)混合制**(核实自官方 pricing 页 + demandsage):

| 档 | 价格 | 席位 | 定位 |
|---|---|---|---|
| **Creator** | $39/mo(年付)/ $49/mo | 单人 | 个人创作者(注:官网主 pricing 页现已主推 Pro 起步,Creator 在部分评测仍列出,存疑其是否对新用户开放) |
| **Pro** | $59/mo 年付 / $69/mo 月付,**按席位** | 1 席起 | 小团队 |
| **Business** | 定制报价(最低 12 个月) | 多席位/不限 | 企业 |

**信用制(credits)关键机制**(核实自官方 pricing 页):
- **常规内容生成不耗 credits**(unlimited word generation);
- **部分用量型功能耗 credits** —— 明确点名 **GEO Hub 与 Agents 按动作(per action)计费**,例如"每跑一次 GEO Hub 报告"扣一次。
- Business 才有 API access / Studio / no-code Agent Builder / 不限 IQ 资产。

**SMB 警示(核实自多篇评测):** 无免费档,只有 7 天试用;Pro $69/席位 远贵于 ChatGPT Plus / Claude Pro($20);Copyscape 查重是**额外付费**;多起"以为取消却继续扣费"的账单投诉;Reddit 用户吐槽"output 越来越 generic"。

## 3. SMB / SEA 视角(马来西亚/东南亚 SMB 真会用 vs 企业虚胖)

**SEA SMB 真会用的:**
- **Brand Voice(上传 8 条样本即成)** —— 门槛极低,SMB 老板最认"写得像我"。★核心。
- **Grid 批量跑**(1000 条产品描述)—— SEA 电商/Shopee/Lazada 卖家的刚需痛点。★
- **Translation Agent(27 语言)** —— 马来语/英语/中文/泰语多语市场刚需。★★ SEA 特别相关。
- **Image Suite 抠图/换背景/产品图标准化** —— 电商卖家日常,秒级、批量,直接省钱。★
- **90+ 开箱 app**(Instagram caption / 产品描述 / 广告文案)—— 短平快,SMB 立刻上手。
- **Chrome 扩展 + Slack** —— 在现有工具里用,零迁移成本。

**企业虚胖(SEA SMB 大概率不碰):**
- **GEO Hub / GEO Agent**(耗 credits,监控 AI 搜索可见性)—— 这是给有品牌预算的大企业玩的"AI 搜索 SEO",SMB 没这焦虑。⚠️虚胖。
- **Studio 自建 custom agent + 全套治理(SSO/SCIM/Audit/Groups)** —— Business-only,SMB 用不到治理层。⚠️
- **Salesforce/BigQuery/Workfront/SharePoint 集成** —— 企业栈,SEA SMB 不用。⚠️
- **Packshot compositing / 16× upscale / API** —— 规模化才划算,单店用不上。⚠️(部分)
- **整个 Business 定制报价 + 12 个月锁定** —— SEA SMB 现金流不友好。⚠️
- **$69/席位定价** —— 对马来西亚 SMB 偏贵(RM ~300+/月/人),FIKIRTIVE 的 credit-pack + 免费额度模型更契合本地。

## 5. 值得偷的 feature 机制(具体、可操作)

**① Grid 的"行=输入、列=agent"批量范式** —— 最聪明。非技术营销人用电子表格心智模型就能编排 AI agent 批量跑;拖一个 agent 当列,每行自动过一遍。对 FIKIRTIVE:SEA 电商卖家"给我 200 个产品各出一条描述+一张标准产品图"的场景,这个 UI 比节点画布更直觉、更"易管理"。核心可偷:**把批量 = 表格,而非流程图。**

**② Brand Voice = 上传 8 条样本自动生成声音** —— 极低门槛的品牌资产建模。不问用户"你的语气形容词",而是"给我 8 篇你写的东西",AI 逆推声音。对 Otto 产品化:这是把"训练 Otto 懂我品牌"变成一个**5 分钟、可重复、可编辑**的动作。可偷:**用样本逆推,而非让用户填表描述抽象品牌属性。**

**③ Style Guide 当"brand guardian"实时标红 + 给替换** —— 把治理从"事后审核"变成"生成时纠偏",且给出可点的 on-brand 替换。对 FIKIRTIVE:符合 founder "安全"第一优先级——品牌越界在产出时就拦。可偷:**违规不是报错,是内联建议一个合规替换。**

**④ Jasper IQ = 一次定义、处处注入、全团队自动** —— 品牌上下文不是每次手动贴,而是配一次后自动进每次产出。对 Otto super-employee:这就是 agent 的"长期记忆自动召回"。可偷:**资产层与生成层解耦——用户管资产(文件),系统自动注入。**

**⑤ per-action credits 只用在"贵动作"上(GEO Hub/Agents),常规生成不计费** —— 混合计费的克制版。对 FIKIRTIVE(已有 credit 引擎):可借鉴"廉价的高频动作不吓用户,只对真正贵的 agent 长任务计 credit",与 founder"ask before spending real money"哲学一致。

## 6. 易管理视角(对齐 founder 第 3 优先级:file-system 风格,可读文件+简单开关)

Jasper 让非技术营销人管理复杂功能的**具体聪明做法**,正是 FIKIRTIVE 该学的:

1. **品牌资产 = 一堆独立、可读、可编辑的"卡片"**(Brand Voice / Knowledge Asset / Audience / Style Guide),每个都是能单独打开看/改的对象,数量还是明码计数(Pro=2 voices/5 knowledge/3 audiences)。★ 这几乎就是 founder 想要的"file-system 风格 + 简单开关"—— 资产不是埋在设置里的黑盒,而是列表里可数、可点、可改的文件。

2. **上传即配置(样本/文件/URL),无参数调优** —— 用户不调 temperature/权重,只喂内容;复杂性藏在系统侧。

3. **Admin Controls = 功能开关(feature toggles)** —— 管理员用开关控团队能用哪些功能,而非配置文件;对齐"简单开关"。

4. **Studio/Grid 全程填表式(选目标/接数据/配 prompt)** —— no-code 表单代替编程,营销人自建 agent"不等 IT"(2025 建了 5800+ app 证明门槛真低)。

5. **治理内联而非事后**(Style Guide 实时标红)—— 让"管理品牌合规"从一项独立工作变成生成时的顺手一点。

**对 FIKIRTIVE 的直接启示:** Otto 的"品牌大脑"应做成一组**可数、可读、可开关的资产文件**(镜像 Jasper IQ 五件套),用户用"上传样本"而非"填抽象属性"来喂;治理(安全)做成生成时内联纠偏而非事后审核。这三点同时命中 founder 的安全 + 效率 + 易管理三优先级。
