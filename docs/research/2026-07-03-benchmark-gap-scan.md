# FIKIRTIVE 对标版图缺口扫描

## AI 内容/创意生成 + 一体化 AI 营销内容工具

### [DEEP-RESEARCH] Jasper(SEA=medium)
- **是什么**:从 AI 文案工具转型成的「营销专用 agentic 平台」;席位制 Pro $59/mo(年付),Business 定制(数百至数千刀/mo);核心卖点是无代码 AI Agent Builder + 品牌语音/知识库 + Canvas。
- **为何值得**:这是市面上最接近 FIKIRTIVE「agentic marketing OS + Otto super-employee」定位的西方玩家——2026 已上线真正自治的营销 Agent(不是 chatbot)、no-code 建 agent、100k+ 付费企业含近 20% 财富 500。它证明了『营销团队用一堆可编排 agent 干活』这条路的商业化打法(席位 + 企业定制),正是 Otto 技能框架要对标的产品化终局。
- **与已覆盖重叠**:和已覆盖的 HubSpot/Salesforce(CRM 侧)、Adobe GenStudio(企业创意)有企业级重叠,但没有一家已覆盖者是『纯 agentic 营销执行层 + 用户自建 agent』这个角度——这是我们尚未研究过的独特机制,不是同类第 N 家。
- **建议理由**:唯一直接对标 FIKIRTIVE 核心论点(agentic 营销 OS)的成熟商业化样本;它的 Agent Builder 定价/打包、品牌语音/知识资产模型、席位 vs 用量的混合计费,直接影响我们 Otto 的产品化与定价决策。founder 关注的『安全/效率/易自管』正好对得上它的 no-code agent 治理。

### [MAP-LINE-ONLY] Copy.ai(SEA=low)
- **是什么**:从文案生成器硬转型为「GTM AI 平台」;席位 + Workflow Credits 计费(Advanced $249/mo/5 席 2000 credits);卖 Workflows + 专业化 Agents(Prospecting/Inbound/ABM/本地化/Deal Coaching)。
- **为何值得**:另一个『把最佳实践编成可重复 agent 工作流』的样本,且明确走 credits 计量的用量计费——和我们的 credits 经济学同源。它的『15+ 营销 workflow + 15+ 销售 workflow』打包法,以及砍掉免费版、涨价的商业化转向,是 credits + agent 定价的活教材。
- **与已覆盖重叠**:机制上和 Jasper 高度同类(都是 agentic GTM 平台),偏销售/GTM 而非内容创意;和 HubSpot 的营销自动化有重叠。作为 agentic 平台的第二家,边际价值低于 Jasper。
- **建议理由**:独特机制已被 Jasper 代表(deep-research 选 Jasper 即可覆盖 agentic 营销这一格);Copy.ai 值得在对标地图加一行标注它的 Workflow-Credits 计费 + GTM(偏销售)倾斜,作为『credits 计量 agent 工作流』的定价参照点,但不必全量报告。

### [DEEP-RESEARCH] invideo AI(SEA=medium)
- **是什么**:文字/单图 → 整条营销视频的 agent;v4 agent 单 prompt 可出最长 30 分钟视频;Plus $28 / Max $50-60 / Generative ~$100-120(内嵌 Sora 2 + Veo 3.1);AI 分钟数 + 图库 credits 计量。
- **为何值得**:这是 Otto『内容生成肌肉』最像的对标:喂一张产品图就自动产出 Amazon A+、360° 产品视频、A/B 广告变体组、hero 广告 reel;『Money Shot』用 4-8 张参考图保真出多镜头商业片。整条脚本→选素材→配音→字幕→多格式导出全 agent 化——正是我们 canvas video flow + 抽帧 + reference-vision 想做的一体化。
- **与已覆盖重叠**:和 Higgsfield/LTX Studio/Grok Imagine 有 gen-video 重叠,但那些是『生成模型/创意工具』,invideo 是『单 prompt agent 端到端产出成品营销视频 + 保真产品』——这层 agentic 编排 + 产品保真是已覆盖者没有的独特机制。
- **建议理由**:直接对标 Otto 的内容自动化终局(一句话出可投放的成品广告 + 产品保真),且把 Sora/Veo 打包进 credits 定价的做法是我们 video-near-cost + 打包溢价策略的关键参照。独特机制多、和现有 canvas 路线图强相关,值得全量拆解。

### [MAP-LINE-ONLY] Icon (icon.com)(SEA=low)

- **与已覆盖重叠**:软件层的『clone competitor + 一键投 Meta』和已覆盖的 AdCreative(见下)、我们自己的 Meta 连接器/G7 重叠;但『真人拍摄 + 软件编排』的混合模式没有已覆盖者代表。
- **建议理由**:混合(真人+软件)模式和它对『AI UGC 信任』的公开定位是有价值的战略信号,值得地图加一行;但物流密集的真人拍摄不在 FIKIRTIVE 打法内,且 US-DTC 定价/供给,SEA 相关性低,不值得全量研究。

### [DEEP-RESEARCH] Pippit (CapCut / ByteDance)(SEA=high)
- **是什么**:ByteDance 把 CapCut Commerce Pro 改名的 AI 营销视频平台;Link-to-Video + 品牌自训 avatar + 产品 feed 摄取 + 直发 TikTok Shop/Shopify + 按视频 A/B;免费 150 credits/周,Starter ~$24/mo(年付)。
- **为何值得**:这是 SEA『用户现在实际在用什么』的答案:背靠 CapCut(3 亿 MAU,印尼是核心市场之一)、直连 TikTok Shop——正是 FIKIRTIVE 起步市场里商家做视频广告的默认路径。它的 product-feed→脚本→avatar→直发电商店面闭环,是我们进场必然要正面撞上的分发+生成一体化玩家。
- **与已覆盖重叠**:生成层和 Creatify/invideo/Higgsfield 有 URL/feed-to-video 重叠,但『ByteDance 分发引力 + TikTok Shop 原生直发 + SEA 装机量』这个渠道护城河没有任何已覆盖者代表。
- **建议理由**:SEA 关键、且是渠道级威胁(不是又一个生成工具而已)。founder 起步市场的商家很可能已在用 CapCut/Pippit;要判断我们是打不过就接入(WhatsApp-first vs TikTok-first)还是差异化,必须吃透它的 feed→avatar→TikTok Shop 闭环、credits 定价与 avatar 自训。

### [MAP-LINE-ONLY] AdCreative.ai(SEA=low)
- **是什么**:AI 广告创意生成 + 转化评分(CNN 打分,号称 >90% 准确,基于 $35B 广告花费训练);对接 Meta/Google/LinkedIn;$29 Startup → $99 Ultimate → $141 Pro → $374 Agency(credits/下载计量)。

### [MAP-LINE-ONLY] Predis.ai(SEA=medium)

## 社媒排期 / 管理 / 分析(Social Media Scheduling / Management / Analytics)

### [DEEP-RESEARCH] Hootsuite(SEA=high)
- **是什么**:老牌企业级社媒管理套件(排期+统一收件箱+社媒监听+分析);按席位定价,Standard ~$99/user/mo、Advanced ~$249/user/mo(年付),AI 全含(OwlyWriter + OwlyGPT 助手)。
- **为何值得**:唯一在主流社媒排期工具里原生支持 WhatsApp 频道排期的玩家 —— 这直接命中 FIKIRTIVE 的 WhatsApp-first 论点,是我们要么正面竞、要么明确差异化的对象。OwlyGPT 已从'写文案'升级成'策略/受众/竞品洞察'助手(接 Talkwalker 实时数据),是同类里 AI 定位最激进的老牌之一,值得看它把'助手'做到哪一步。
- **与已覆盖重叠**:排期/收件箱/分析核心与 Buffer 重叠,企业销售动作与已覆盖的 HubSpot/Salesforce 部分重叠;但 WhatsApp 原生频道 + OwlyGPT 助手是已覆盖 18 家里没有单独研究过的两个点。
- **建议理由**:两条我们没研究过的独特线:(1) 主流社媒工具中唯一的 WhatsApp 频道原生排期 —— 与我们 WhatsApp-first 定位正面相关;(2) OwlyGPT 作为'策略级 AI 助手'的能力边界,是判断'我们 Otto 全操控 vs 它的助手'差距的最好参照。此为 SEA 关键 + 独特机制,够格全量。

### [MAP-LINE-ONLY] Later(SEA=medium)
- **是什么**:原视觉排期工具(IG-first),2025 以 $250M 收购 Mavely 后转型为'社媒管理 + 网红/创作者带货'全漏斗平台;推出 EdgeAI 预测引擎(用十年创作者+电商一方数据预测 ROAS)。
- **为何值得**:转型方向本身是个信号:排期工具单打独斗不够,要往'可归因的转化/带货'走。EdgeAI 用专有创作者+commerce 数据做效果预测,是我们没研究过的独特机制(不是通用 LLM 写文案,而是数据驱动的效果预测);对 FIKIRTIVE 的 perf-marketing + 资产愿景有参照价值。
- **与已覆盖重叠**:排期核心与 Buffer 重叠;网红/创作者带货这条线是全新的,已覆盖 18 家无人代表(Higgsfield/LTX 是生成侧,不是创作者商务)。EdgeAI 的预测打法与已覆盖各家的 AI 助手不同。
- **建议理由**:EdgeAI 预测机制 + 创作者带货转型是有价值的对标点,但主体是 creator-marketing/affiliate 商务,偏离 FIKIRTIVE 的 Otto-操作排期核心,SEA 相关性中等(其创作者网络主要在北美)。加一行捕捉'排期→可归因带货 + 数据驱动预测'这个方向即可,不必全量。

### [MAP-LINE-ONLY] Planable(SEA=low)

- **建议理由**:定价模型(per-workspace vs 我们的席位+credits)和多级审批流是值得记的对标点,但整体仍是排期/协作工具、SEA 相关性低。地图加一行标注这两个机制,供后续定价与审批 UX 设计参考;不够格全量。
