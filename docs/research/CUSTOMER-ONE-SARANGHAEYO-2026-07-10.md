## 3. 效果对赌（月底拿三张单子给老板）

按**回执脊柱**口径分三级，越往下越硬也越难，诚实标注。老板月底能亲手核对，不听"我验证过了"。

**① 源观测（铁证 · 100% 我方日志，不容抵赖）**——证明 Otto 真在干活、干了多少：
- 发布内容 ___ 条（FB/IG/TikTok 分平台计）
- WhatsApp 询单接了 ___ 条、其中转成订单意向 ___ 条
- 会员唤回群发 ___ 条、触达 ___ 人
- 平台自报曝光/覆盖 ___ 人次（平台数，非我方，标注来源）
- 收集到新评价/UGC ___ 条

**② 强归因（带追踪 · 中等把握）**——把"钱"接回到 Otto 的动作上，**月初第一天就要埋码**，否则月底补不回来：
- 给 Otto 推的优惠配**专属 voucher code / UTM 链接 / "报 Otto 优惠"暗号**
- 月底数出：走了 Otto 钩子的订单 ___ 单、金额 RM ___、其中唤回老会员 ___ 单
- 这级能诚实说"这些单子是 Otto 带来的"，因为有码可查

**③ 增量（最难 · 月一大概率给不出干净数，诚实降级）**——Otto 是否带来了**净新增**、而非本来就会发生的生意：
- 要看他们后台真实 GMV / 复购率 / 客单价的同比变化——**但 Raya 季节性极强，单月环比会被季节噪声污染，不能直接归功 Otto**
- 想干净说"增量"，需要留**对照组**（例：一半到期会员发唤回、一半不发，比复购率差）+ 至少 2–3 个月基线
- **月一诚实交付 = 满级源观测 + 部分强归因；增量留到第 2–3 个月**，不吹。

> 一句话给老板：**月底我保证给你两张能亲手数的单子（Otto 做了多少 + 走 Otto 优惠码的钱有多少），第三张"净赚多了多少"要等两三个月和你的后台数据才敢签字。**

## 4. 诚实栏（哪些证据薄 / 哪些要等真数据）

**证据薄、只能当量级参考的判断：**
- **所有社媒粉丝/评价数都是搜索引擎快照**，非实时，可能滞后数周到数月：FB ~7.3 万、IG ~4,270、TikTok 6–6.7 万都只是**量级**，不是精确值。
- **"最近 30 天是否活跃"查不到**——只读工具够不到动态 feed，能锚定的最新内容是 2026 Raya 季（约 2–3 个月前）。**不能据此判"账号已沉寂"**，这是工具局限不是结论。
- TikTok "每日 11am–5pm 直播" 只有单一来源、未复核。
- **Shopee 店的粉丝/评分/SKU/销量全被反爬挡死**——完全盲区，不代表商家没数据。
- 公司注册细节（SSM 403 被墙）靠二级招聘名录互证、非一手；董事/股权/实缴资本查不到；页脚 583246-A 与名录 200201015583 是否同一实体新旧编号，未官方核实（不作红旗，仅存疑）。
- 门店数 = 1 已确认，但 store-locator 是"多州可选"的 UI 外壳，不能 100% 排除曾/将有第二店。
- 会员"会员价"到底打几折、推荐计划好友各得多少 credit——官网都没写明数字，机制不透明。
- 是否存在正式 B2B / reseller 分级批发（可能走 WhatsApp 私下洽谈、没上官网）——无法证实也无法证伪。
- "Google 排名"判断基于有限次 WebSearch 采样、非严谨 SERP 审计；GBP 真实星级/评论/照片需人工真机开 Google Maps 核；网站 schema.org / meta 是否优化因抓不到 HTML head 未核实。
- 已排除的同名噪音（别混）：印尼同名生活家居店 lovesaranghae.com / @saranghaeyo.store、菲律宾打字 App "Sarang Hero"、韩国护肤品牌 Saranghae——都**不是**这家。只认 saranghaeyo.com + IG @saranghaeyowedding。

**必须等到"真数据"才能定的（月一第一周就去要连接权限）：**
- **他们的 EasyStore 后台**：真实 GMV、客单价、复购率、流量来源——这是定 Otto 主攻方向、也是第 3 节算"增量"的地基。
- **Shopee 卖家后台**：那条被反爬挡住的销量/评分/SKU，只有登录后台才看得到。
- **他们的广告账号**：现在到底有没有在投广告？投多少？ROAS 多少？——决定"广告"这条腿要不要 Otto 接。
- **会员名单的真实规模与活跃度**：决定第 2 件唤回工单能捞回多少钱。
- **WhatsApp 真实询单量**：决定第 1 件接单工单的省时/增收量级。

**给 founder 的一句提醒**：上面每一个"未核实"都不是拍脑袋猜的空白，而是只读侦查够不到的边界。要把它们变成硬数字，靠的不是再搜一轮，而是**让 Saranghaeyo 把后台连进城里**——那一刻起，Otto 的对赌就能从"源观测"往"增量"一路兑现。
