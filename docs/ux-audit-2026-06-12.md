# Artlio Studio — pre-test UI/UX audit (2026-06-12)

Two independent engines: a 12-lens multi-agent sweep (91 findings → 60 synthesized,
each adversarially verified) + an independent Codex correctness pass. Merged + deduped
below. `[both]` = flagged by both engines (high confidence).

**Verdict:** the desktop happy path works (generate → storyboard → elements → assets →
editor), but it's **not test-ready**: it ships visible mock chrome on a money product,
the nav collapses on mobile, the core @mention wedge is unwired, and several paid paths
can mis-spend or hide failures.

## P0 — blocks testing
1. **Mobile: below 1024px the sidenav is hidden with no fallback → app unreachable / trapped on the first surface.** `StudioShell.tsx:79`. Fix: hamburger drawer below lg, or a real "desktop only" interstitial. (You test on a phone — this matters.)
2. **Studio editor tab has no unsaved-cut guard → switching tab/project silently discards timeline edits.** `[both]` `VideoEditor.tsx:28`, `StudioShell.tsx:62`. Fix: lift dirty state + confirmLeave like the /editor route already has.

## P1 — money / trust / data-loss / core
3. **Default prompt pre-filled + Generate enabled on load → one click/Enter spends real money on an unauthored prompt.** `GenSpace.tsx:52`. Fix: `useState("")` + move sample to placeholder.
4. **Fake user "Tessa Bright" + fabricated "768 CR" balance on every screen.** `[both]` `StudioShell.tsx:115`. Fix: render real user prop; remove/hide credits+Upgrade until billing exists.
5. **Double-spend on duplicate Generate clicks/tabs** (gen has no active-job guard, unlike refgen/render). `[codex]` `gen-actions.ts:46`. Fix: server active-guard / idempotency.
6. **Stale image price $0.035 → fal now $0.04.** `[codex]` `gen.ts:34`, `refgen.ts:34`. Fix: update constant.
7. **FPS sent to fal but not priced** (LTX-2 25→50fps bills above the shown "~$"). `gen.ts:81`, `GenSpace.tsx:161`. Fix: price fps or drop the fps control.
8. **Batch failures collapse into one banner; a charged-but-failed clip vanishes** → can't tell which failed, may re-run + pay twice. `GenSpace.tsx:116`. Fix: per-clip status/failed tile.
9. **Storyboard textarea never resyncs to server, then overwrites it on Generate/blur → spends on the wrong prompt.** `Storyboard.tsx:34`. Fix: `useEffect(()=>setPrompt(shot.prompt),[shot.prompt])`.
10. **@mention element refs are DEAD in both composers while the UI promises them** (the wedge). `Storyboard.tsx:209`, `GenSpace.tsx`. Fix: wire the Tiptap Composer in, or remove the @-promising copy.

17. **Native `<select>` option lists risk white-on-white (unreadable model/duration menus).** `GenSpace.tsx:322`, `Storyboard.tsx:123`. Fix: solid dark bg on select + option.
18. **Gen-space Retry/X are dead non-interactive SVGs** (look live, do nothing, keyboard/SR-invisible). `GenSpace.tsx:197`. Fix: real buttons or remove.

21. **Studio editor has no mobile read-only guard** — on a phone you can tap Export → real render spend (the /editor route guards this; the Studio tab doesn't). `VideoEditor.tsx:22`.
22. **Unknown/stale `?p` silently falls back to the oldest project** (could generate against the wrong project). `studio/page.tsx:34`. Fix: notFound / "showing X" notice.
23. **/library redirect drops `?p`** (lands on oldest). `[both]` `library/page.tsx:7`. Fix: forward `p` (+`e`).
24. **Gen-space "Sessions" rail is mock + a dead "New session" button.** `GenSpace.tsx:25`. Fix: remove until real.
25. **Output can be lost after paying** — `spent=true` before output rows durably stored; a store failure → terminal FAILED but charged. `[codex]` `gen.ts:182/216`. Fix: resumable persist or charged-failed reconciliation flag.
