## 0. 北极星

**让 FIKIRTIVE(Otto)的创作体验 = Grok Imagine 的创作画布体验** —— 画布为主、产物即有状态对象、选中即就地进化、agent 编排 —— 只把品牌/渠道/计费/合规换成 FIKIRTIVE 自己的。**功能不变,只换范式。**

**⚠️ 重要更正(经独立审查):** 目标是 **100% Grok 的「创作画布交互手感」**,不是字面 100% 复刻 Grok 全部功能 —— 因为 Grok 有几样东西被 FIKIRTIVE 宪法**永久禁止**(见 §3-B)。把"100% Grok"当口号会暗地里承诺违宪的东西。

## 3. 边界三栏(经独立审查 + 创始人逐条裁决)

**A · 必须不同 = 合规适配(照抄会侵权/违宪)**
| 项 | Grok | FIKIRTIVE |
|---|---|---|
| 品牌/Logo/皮肤 | Grok | 自有(skin=gb) |
| 图片计费 | 直生成 | 直生成 · 宪法例外①「余额即闸」(生成动作=审批+余额硬闸+失败退款+防双扣,不改宪法) |
| 视频计费 | 直生成 | **保留花费确认** |
| 对外发布 Share | 一键发 X | **一期只 Download,不发布**;二期发自有渠道(Meta/IG/TikTok)**且过审批闸**(第4条 fail-closed),非零摩擦秒发 |
| 并行自动生成 | 无上限 | **做合规版:并行+创始人设上限+routine 四件套(预算/范围/kill switch/事后摘要)** |
| 模型选择 | 黑箱 | 黑箱(一致) |

**B · Grok 有,但我们永久不做(宪法第 8 条 / 未拍板)**
| 项 | 裁决 |
|---|---|
| 对外 MCP(外部 agent 操控我方) | **不做**(第8条) |
| 用户自建可分享模板(社区分发) | **不做/二期再议**(未拍板) |
| 年龄门(NSFW 相邻) | **默认不做** |
| 外部账号 connectors(Gmail/Drive/Salesforce) | 创始人要保留 → 走 §7 单独轨道(需先改第8条,不在画布分期) |

**C · 实现期不可违背(即使 Grok 无此概念)**
- **第6条 租户铁幕**:A2/C2/I2 的新数据模型全链路 `requireOwner`+`ownerId`,新增 model 进 TENANT_MODELS 登记;跨租户零泄漏。
- **第5条 通道费独立账道**:任何对外发布产生的渠道费永不混入 credits。
- **第7条 双模对等 + 单一动作层**:每个新 canvas action 出生即配 Otto skill 或明示豁免;人 UI 与 Otto 共用同一动作层;过 Parity Manifest CI 闸(就地续写=真实生成动作,不能走 VISUAL 豁免)。

## 5. 不监守自盗 · 验收协议(硬性 · 已收紧)

1. **验收方式 = 对抗式 workflow**:每期派专门"证伪、挑错"的独立 agent(默认判不通过,除非有硬证据),产出创始人可核对的证据包(Grok 并排录屏 + 逐条走查表)。UI/流程/手感由 workflow 扛。
2. **钱的最后一签归创始人**(workflow 不能替):凡触及 spend 的判据(视频确认、并行上限、connectors),验收包必须含 —— ①money-safety-review 全文 + 触发的代码 diff(哪行是那道闸);②创始人一句"钱路白话附言"(会不会花钱/哪个动作扣/上限多少/取消路径),**创始人签这句**;③一次创始人可做的破坏性测试(独立会话触发真实视频生成,取消后**供应商侧无调用**为证,不是看 UI)。**spend 判据永不能仅凭并排录屏+打勾通过。**
3. **走查表三栏**:判据 / 证据物(文件名+录屏时间码)/ 验收结论;三者缺一该条即未过,空 checkbox 不构成绿。
4. **缩水即违约**:§2 任一条被"做不到/先不做"处理,必须显式上报创始人。
5. **不自合**:PR 不自批自合;CI 三 job 全绿 + 独立 review(REVIEWER-PLAYBOOK)。
