# Harmony 04 —— 定价 Costing 模型

> **性质**:harmony 交付物 4/6。输入数据全集见同目录 `harmony-04-costing-inputs.md`(每个常数带 file:line 出处)。
> 用法:founder 补齐 §四 的三个数字 → §三 的决定自动落地。**在此之前,任何档位定价不得写死**(宪法第 5 条 + costing 先行令)。

## 一、收入公式(双轨,G 区已拍)

```
月收入(每 org)= 创作席数 × P_creator + 审批席数 × P_approver     ← 席位轨
              + max(0, credits 消耗 − 订阅内含额度) × credit 单价   ← 用量轨
月毛利       = 月收入 − Σ(各花费点 COGS) − 通道费(直传,零毛利) − 固定成本分摊
```

## 三、三个悬而未决的定价决定(数据到位即落)

| 决定 | 条件公式 | 预备判 |
|---|---|---|
| **credits 滚存** | 滚存上限 = 月配额 × 1(敞口有界:最坏月成本 ×2);若毛利 <35% 则降为 0.5× | 滚存上限制(G-03 已拍方向) |
| **免费档** | 能力全开 + 100cr;若 CAC 数据显示不痛不痒,升 150-200cr(获客成本仍 <RM20) | 维持 100cr 起步 |

分市场差异定价(G-06):MYR 基准价 × 市场系数表(config 层,如 SG 1.6 / ID 0.7),**系数永不硬编码**。
