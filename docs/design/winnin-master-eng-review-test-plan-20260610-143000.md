## Affected Pages/Routes
- `/`（工作台主页）— 空状态引导、实体库侧栏、@编辑器、镜头板、生成历史/候选区
- `/api/upload/*`（预签名签发、完成回调）— 上传链路的服务端收口
- `/api/export/*`（ComfyUI 模板包、实体包、联络表导出）
- 登录门页 — 最薄保护（密码/魔法链接）+ 速率限制

## Key Interactions to Verify
- 拖图到任意位置 → 自动建实体（缩略图 + 名字建议）
- 输入 `@` → 候选下拉显示参考图缩略图 → 选中插入原子芯片 → 芯片删除/退格/复制为纯文本行为
- 多 GB 视频分片上传：暂停/恢复/断网重连/关标签页后重开恢复
- 重复文件上传 → 秒传（哈希命中，不重复存储）
- 候选区"未挂载"视图 → 挂载到镜头 → 镜头状态机推进（非法跳转被拒）
- 尾帧→首帧按钮：从已挂载视频产出提取尾帧入下一镜参考槽
- 实体改名 → 旧生成历史记录的快照不变
- 实体包导出 → 导入 → 再导出字节级一致；恶意 zip（路径穿越/超大）被拒并报明确原因

## Edge Cases
- 空状态全线（空实体库/空镜头板/空候选区/空历史）必须是可操作引导，不允许纯"暂无数据"
- 上传不支持的格式 / 超限大小 → 入队前明确拒绝
- 损坏视频文件 → 灰色占位 + "损坏"角标，不阻塞其他收录
- 登录门连续失败 → 速率限制生效
- 候选区一次涌入大量文件 → 列表虚拟化不卡、worker 队列有界并发
- ComfyUI 模板重复 ARTLIO: 标题 → 响亮报错列出冲突节点（不静默选择）

## Critical Paths
- 首次使用全流程：登录 → 空状态 → 拖图建第一个实体 → 写第一条 @prompt → 导出模板包（M0 的灵魂路径）
- 上传→收录→挂载→定稿 全链路（含 worker 哈希校验/ffprobe/缩略图/尾帧四步任务与失败重试→死信）
- 5 条不变量测试全绿 = 阶段一完成硬条件（实体包往返/软删除完整性/快照不可变/恶意包拒收/上传恢复完整性）
