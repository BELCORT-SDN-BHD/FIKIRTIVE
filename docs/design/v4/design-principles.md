# Fikirtive 设计原则(一页)

> 状态:**定稿**。第 1–13 条 Founder 2026-08-20 逐条拍板,13/13 全批;第 14–17 条为同日品味基线审计催生的增补,Founder 授权编排者裁量收编(其中第 14 条取弱化形);第 18 条源于 Founder 同日对钱路显著度的裁决,Founder 亲批。第 4、5、18 条修订与第 19 条增补源于 Founder 2026-08-21 六裁决(珊瑚品牌标豁免/棱镜边具名/余额收归 Billing + 批量账本口径/外部指标白名单;同批:ink3 回写 colors.json)。同日确认生效方式:本页与 brand guidelines、`docs/brand/colors.json` 并列为设计权威第三件,品味判官 + Emil 技能硬挂钩自此常设。
> 适用范围:产品界面全部(七门 dashboard、canvas 工作区、Otto 面板、登录与邮件内嵌 UI)。营销物料归 brand guidelines 管。
> 用法:品味判官对每张 UI PR 逐条对照本页;违反任何一条 = 打回,不做权衡讨论。方向权威 = 柔光棱镜(本目录 `design-direction.html`)。

## 甲 · 总纲

**1. 减法优先。**每个上屏元素都必须说得出它替商家干什么活;说不出就删。两个元素干同一件事,删一个。加新东西前先问「删了谁受损」。
判法:判官指着任何元素问「删了它,商家损失什么?」答不上来即违规。

**2. 诚实压倒热闹。**每个数字都有真实来源;空账号看到诚实的空 + 一个真实的下一步;没通电的能力不上屏、不承诺。假数据、假进度、假热闹 = 品味破坏,不是小疵。
判法:任选一个屏上数字,顺藤摸到数据来源;摸不到即违规。

**3. 有迹可循、花钱先看见。**凡 AI 在做的事都留痕:排队可见、单条可取消、历史可查(canvas 的 agent log 是标准形)。凡要花 credits 的动作,按下之前价格已在屏上。
判法:找一个正在跑的 AI 任务,验证能看到它、能取消它;找一个花钱按钮,验证价格先于点击可见。

## 乙 · 色彩

**4. 人类动作墨黑,珊瑚只属 Otto。**一切人类动作按钮 = 墨黑 `#16171C`。珊瑚 `#EC5828` 只标记「AI 在场」:Otto 气泡、进度环、生成中的呼吸灯。商家一眼分清「我做的」和「AI 在做的」。唯一例外:fikirtive 品牌标(F 标)本身用珊瑚——商标就是品牌,一处静态 logo 不稀释「珊瑚 = AI 在场」的信号(Founder 2026-08-21 批;与 colors.json `brand.$rule` 对齐)。
判法:全屏截图,逐一指认每处珊瑚——除品牌标外,有一处不是 Otto,违规。

**5. 渐变糖有配额。**紫/桃/天蓝渐变只做内容点缀(开工砖、模板卡、空态插画),**每屏最多两处**,135° 双 stop,永不上页面框架(导航、页头、表格、按钮)。整屏配比守 90(中性)/ 8(渐变)/ 2(珊瑚)——颜色是盐,不是主菜。唯一具名例外:Create composer 的棱镜边 = 120° 四停点(紫→桃→天蓝,token 色),全产品唯一允许的多停点渐变(Founder 2026-08-21 批);再添多停点渐变须 Founder 具名入法,不得类推。
判法:数渐变,>2 违规;渐变出现在框架件上,违规;棱镜边以外出现多停点或非 135° 渐变,违规;棱镜边自身偏离具名参数(120°、四停点、紫→桃→天蓝 token 色),违规。

**6. token 之外无颜色。**任何颜色必须来自 `apps/web/app/globals.css` token(源头 `docs/brand/colors.json`)。PR 里出现裸 hex 色值 = 打回,无例外。
判法:diff 里 grep 裸色值。

## 丙 · 排版与结构

**7. 一副字体,两种用途。**Geist 写一切界面文字;JetBrains Mono 只写数据(ID、代码、成列数字);数字成列必开 tabular figures(等宽数字,列才对得齐)。UI copy 用 English sentence case;行文写 Fikirtive,wordmark 画全小写 fikirtive,全大写 FIKIRTIVE 已停用。
判法:非 Geist/Mono 字体残留、Title Case 残留、FIKIRTIVE 残留,见一处违规。

**8. 一页一网格,一页一种卡。**每页一套网格、一套间距阶、一种卡片语言;圆角、边框、阴影全用 token 阶。一页出现三种不同长相的卡 = 拼贴,打回。
判法:截图上画网格线;对不齐、卡样式混杂即违规。

**9. shadcn 原语,不手搓。**dialog、tabs、select、skeleton 等一律 shadcn/ui 原语 + 样张页 `/design-system` 现役 token。新组件或新变体先进样张页,再上产品——样张页是组件唯一橱窗。
判法:diff 里出现手搓的对话框/页签/骨架屏,违规。

**10. AI 味违禁表。**以下形状见即打回:居中大 hero + 三列 feature 卡的模板布局;icon+标题+副标题三件套铺网格;emoji 当装饰;夸饰文案(Supercharge / Unleash / Elevate 之类);渐变文字;为填空而生的卡片墙。
判法:对照违禁表逐形状扫一遍。

## 丁 · 动效与响应

**11. 动效频率法则。**商家每天做几十上百次的动作(键盘触发、切页签、command palette)**零动画**;常见交互(hover、下拉)≤200ms 轻动效;偶发件(modal、drawer、toast)150–300ms;只有仪式性时刻(首次 onboarding、发布成功)允许庆祝。键盘触发的动作永不动画。
判法:对每个新增动画问「商家一天见它几次?」高频却在动,违规。

**12. 动效手感字典。**全产品一个手感:进出场用强 ease-out `cubic-bezier(0.23,1,0.32,1)`;屏上移动用 ease-in-out;一切 UI 动效 <300ms;按钮按下 `scale(0.97)`(100–160ms);出场永不从 `scale(0)` 起(最小 0.95 + opacity);popover 从触发点长出(transform-origin);禁 `transition: all`;禁 ease-in;`prefers-reduced-motion` 下保透明度、去位移。
判法:Emil 检查表逐条过 diff(本条即 Emil 技能硬挂钩落点)。

**13. 响应时限。**按下任何东西,100ms 内必须有可见反馈;超过 300ms 的等待必须有诚实的进行中状态(骨架屏/spinner,不假装已完成);超过 1 秒的生成类任务必须进 agent log——排队、可取消、留痕(接第 3 条)。
判法:秒表实测三档;缺一档违规。

## 戊 · 增补(2026-08-20 品味基线审计催生)

**14. 渐变有承载位,不用须说明。**设计每扇内容门必须明确回答「渐变承载位在哪」(开工砖、模板卡、空态、数据卡四类之一);答「无」必须给理由,由品味判官记录。为凑配额而装饰同样违规(接第 1 条)。
判法:问设计者渐变承载位;答不出又无理由,违规。

**15. 一扇门一个名字。**导航条目、页面大标题、浏览器标题同名;名字只在 `packages/core/src/navigation.ts` 落一份,页面读它,不许再写第二遍。
判法:三处对照,不同名即违规。

**16. 一屏一个主行动。**一屏最多一颗主按钮;空态里的 CTA 与页眉 CTA 二选一,不许同屏。
判法:数主按钮,>1 违规。

**17. 同一句话只说一遍。**同一事实或说明,全产品只有一个说话位;其它地方链接或指过去,不逐字复述。
判法:同一句在 ≥2 处逐字出现,违规。

**18. 钱在决策点,不在空气里。**价格只出现在承诺动作旁(花钱按钮、审批卡);余额只住 Billing 一处(Founder 2026-08-21 裁决删除 Home KPI 巡检位,Billing 为唯一余额权威);只有余额不足或扣费异常才主动上屏;Otto 不复述屏上已有的价格;免费路径可以标 free。批量花钱动作在账本记一行、件数写明(如 ×4 · 12 cr)——一次决定一行账,账本不被批量刷屏。「花钱先看见」管的是决策那一刻,不是让余额时时刻刻挂在屏上——诚实不等于唠叨。
判法:余额出现在 Billing 以外任何一屏,违规;价格出现在承诺动作旁以外,违规;批量扣费在账本多于一行,或该行未写件数(×N),违规。

## 己 · 增补(2026-08-21 Founder 六裁决)

**19. 外部指标过白名单。**渠道接通后回传的真实指标才允许上屏,且每个指标入屏前先过一问「这数字帮商家做什么决定?」——答得出才登记进白名单;名单外的外部数字不上屏,渠道未接通时一律不上屏(接第 2 条)。现役白名单:profile visits(Home 接通后表现卡,2026-08-21 批)。
判法:指认屏上任一外部来源数字——不在白名单,违规;渠道未接通仍展示,违规;顺藤摸不到渠道真实回传(第 2 条判法),违规。
