# 产品与功能参考资料

这里保存有助于理解产品、功能与历史判断的材料。

这些文件是 **reference（参考资料）**，不是当前范围、优先级、批准、验收或执行权威。开始具体开发时，应从当前 Founder 指令与对应任务重新确认细节，并只加载与该任务直接相关的参考资料。

## 已保全资料

- `consultant-dossier-2026-08-02.md`：2026-08-02 的产品与工程现状快照；其中流程、CI 和治理描述已被后续 harness reset 取代。
- `creation-root-map-2026-08-02.md`：Creation 板块五类根因与证据地图。代码位置和状态是当日快照，实施前必须重新验证。
- `canvas-convergence-draft-2026-08-02.md`：唯一画布方向的功能草案。它保留产品意图，但不是已批准的实施计划。

## 使用规则

1. Blueprint 提供长期产品北极星。
2. Reference 帮助理解可能性和历史背景。
3. 当前任务决定本次要做什么，以及何时算完成。
4. 代码、数据库约束和测试证明实现是否正确。
