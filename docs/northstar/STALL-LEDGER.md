# 宕机点台账 · Wave C1

> 这份台账把 12 条常用路径走了一遍,记下每一处「面包店老板会在这儿愣住」的地方。尺子只有一把:**这一刻,一个只会做面包、不懂后台的老板,是看不懂(懵)、想做却被挡住(卡)、还是怕出事没人接(慌)?**
>
> 三个类别 = 三种当场的心情:**懵**(第一眼不知道这是什么 / 从哪下手)、**卡**(知道想干嘛,却被空框、术语、灰按钮挡住)、**慌**(牵扯到钱 / 误发 / 失败,却没有一句人话和一条出路)。**量级**是施工成本:**S** 小改(文案 / 默认值)、**M** 中等(加一个组件 / 一段逻辑)、**L** 大件(补整套失败态 / 空态 / 上下文接力)。每条末尾灰字是给施工的 `文件:行号`。

**共 73 条** · 懵 20 · 卡 31 · 慌 22 · 无跨路径重复元素(12 条路径各走各的屏,未合并)

投票方式:每条后面三个格子勾一个 —— **☐ 要**(该接) · **☐ 不要**(不改 / 现状可接受) · **☐ 改**(方向对但接法要调,旁边写一句)。
