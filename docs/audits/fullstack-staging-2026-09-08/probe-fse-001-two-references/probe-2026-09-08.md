### 3.2 我们今天的请求形状（`packages/generation/src/byteplus.ts`）

- 视频提交在 `L493`：`POST ${ARK_BASE}/contents/generations/tasks`，`ARK_BASE=https://ark.ap-southeast.bytepluses.com/api/v3`（L100）。
- `content` 组装在 `L467–486`：
  - 首帧＋尾帧（两张都带 role）：`{type:"image_url",image_url:{url},role:"first_frame"}` + `role:"last_frame"`（L472–473）；
  - 只有首帧：**不带 role**，一张 `image_url`（L476，注释：引擎按位置读作首帧）；
  - 元素参考照（#785）：逐个 push `role:"reference_image"`（L480–483），**数组顺序即引擎编号，不排序不去重**；
  - 参考视频：`role:"reference_video"`（L484）；最后一条是纯提示词 text（L486）。
- 张数硬闸：首帧/尾帧/参考照共用 `MAX_VIDEO_IMAGE_PARTS = 9`（`packages/core/src/gen.ts:184`，超了在**付费前**抛错），并且参考照与首帧/尾帧/参考视频**互斥**（L446–453，判据 `videoReferencesRide`）。
- 顶层参数：`resolution`、`duration`、可选 `ratio`、`generate_audio`、`watermark:false`、`execution_expires_after:3600`；注释明确 `seed / camera_fixed / frames` 三个**不发**。
- 拒收归类在 `L244`：只有 `what === "video submit"` 且 `referenceImagePersonRejected(detail)` 为真时，才抛 `permanentInputError(REFERENCE_IMAGE_PERSON_REJECTED)`（终结、不重试、可证明零花费、退款）。判据函数在 `packages/core/src/gen-failure.ts:321`：`error.code === "InputImageSensitiveContentDetected.PrivacyInformation"` **或**消息匹配 `/The request failed because the input image 'content\[\d{1,3}\]' may contain real person/`（`L290-291`）。fail closed：认不出的 4xx 一律走通用重试路。

1. **单价没能从 CLI 现查**。`arkcli pricing models` 与 `arkcli resources list` 都被同一个错误挡住：控制面 SSO 已过期（`arkcli auth status` 里 `byteplus_sso.expired=true`、`control_plane_auth.status=needs_login`，数据面 API key 仍有效）。按指令**没有尝试登录**。估价改用仓库钉点 `packages/core/src/cost-pins.ts`（2026-08-29 arkcli 实查牌价：$3.50/M 无视频输入档；$0.035/张图）＋ `packages/core/src/gen.ts` 的 480p 最差比例 10,044 tok/s。回执 `usage.total_tokens=50638` 与估价的 50,220 只差 0.8%，口径互证；但**今天的牌价本身未复查**。
2. **商品照是 Seedream 纯文生的，不是商家真机拍摄的照片。** 本机没有任何无人脸真实商品照（`preserved/` 与本地存储里那 10 张 jpg 全是五名演员的特写/全身）。所以本次只证明了「Seedream 血统的商品图」这一格；**商家上传的真实照片（非 Seedream 血统）配演员原图会不会被收，未实测**。商品照无人脸，按已知机制（拒收句子专指「input image may contain real person」）应当不受影响 —— 这是推断，不是实测。
3. **只跑了 `reference_image` 一种角色组合。**「演员原图作 `first_frame` ＋ 商品照作 `reference_image`」这一混合形态**未实测**（我方代码 L446–453 今天还把这两者判为互斥，会在付费前自己拒掉）。若施工要走「首帧＝演员」那条路，值得再花约 $0.18 单独验一次。
