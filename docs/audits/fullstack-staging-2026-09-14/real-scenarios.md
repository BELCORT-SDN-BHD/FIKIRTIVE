# 更多真实商家测试：执行清单

批准依据：2026-09-14 Founder「可以，但是除此之外，我还要你自己计划更多真实的测试。」范围与 US$20 生成预算见 [plan.md](plan.md)，US$16 暂停。此文件设计测试，不声称已执行。

## 执行与证据约定

每项记录开始/结束时间、部署sha、设备/浏览器、脱敏租户别名、操作截图或文字、实际结果、job/refId和只读数据库差量。账号、一次性码、分享bearer、密钥不得进入外发或持久化报告；实际工具截图曾显示测试邮箱，尚未持久化脱敏，须处理后才能外发／入库；没有完成全审计秘密扫描。截图不足不补造；记录无法获取的证据。

清理边界适用于每项：全部使用本轮专用测试夹具并加日期名字；保留远端测试资产/记录与账本，不擅自删除远端对象或数据；仅关闭自己创建的标签、退出测试会话、还原本浏览器离线/视口。任何撤销权限/分享、线上故障、外部发送独立确认；数据库及故障演练只在隔离本地跑。新邮箱/Google夹具不可用就NOT RUN，不能冒用身份。

价格分开记：商家确认卡 credits、账本 credits、供应商美元估算、供应商实际账单。聊天/理解也可能付费，先查实际路由；真实生成批准限额不自动覆盖未说明的外部付费动作。无价格回执不得猜费用。整组预算不足不缩样本后冒充原验收。

## 首批顺序

1. 先 REAL-13、25、27、28：零生成费用检查隔离、正式路由和权限，避免在错误租户花钱。
2. REAL-01/02、12：用受控账号与自有素材准备真实夹具，同时核登录、理解、文件与备份。
3. REAL-03 一条人物商品视频：把 REAL-07/14/15/20/24/30 合在同一单观察，最大化每笔费用的证据。
4. REAL-04、06：无人物基线、variation和幂等，用最少必要单数检验独立风险；REAL-08只复用自然失败。
5. REAL-05/16/17/22/26等不触发付费的交互补齐；REAL-09四长一短并发组仅在整组报价可容纳剩余额度时执行，不能以两视频代替四视频验收。
6. 到US$16暂停，列出已完成与还欠的真实证据；预算不足项NOT RUN。无新增付费模型探针。

## 路由核对

当前/campaign虽保留page取数组件，但父campaign/layout.tsx统一redirect Home；/schedule/page.tsx同样redirect。navigation.ts:311–323明确Beta停放，两者只验旧入口重定向，不验正式Campaign/排期功能。proxy.ts是鉴权墙，不执行这些停放跳转。/settings为工作区身份设置。CRM虽然有page文件，`apps/web/app/crm/page.tsx:4–22`明确全段已收起、重定向首页；不把文件存在等同正式可用CRM。`apps/web/app/otto/page.tsx:8–44`是旧入口重定向，按`packages/core/src/navigation.ts`核目标。design-system/product-patterns是设计参考路径，单列可达性，不冒充商家正式功能。
