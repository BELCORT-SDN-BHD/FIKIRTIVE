## Dormant、别名与地址纠正

- 旧 `#door-billing`、`#door-connections`、`#door-preferences` 不作为 Dashboard 顶层 route；入口收在 Settings 或 `/billing`。
- `/campaign/calendar` 收敛到唯一 `/schedule`；`/approvals` 只是保留 query 的 `/campaign/workbench` alias。
- Otto IQ panes 是 `/brand?tab=...`，Settings panes 是 `/settings?section=...`；旧矩阵列出的多条子路由并不存在，不能用文档先创造 route 事实。
- `sample data`、prototype/debug controls、fixture notification/article/campaign/approval/routine 数据只用于非 production parity。
