# scripts 目录

- `ci/`：CI 与本地共同使用的质量入口。
- `tools/`：仍会重复使用的诊断、seed、维护或明确授权的外部操作工具。
- `archive/`：历史一次性验证；仅供查证，不是当前项目流程或权威。
- 根目录：产品仍需要的少量独立检查或维护脚本。

项目开发的标准检查只有 `pnpm quality`。不要把 agent 编排、claim、reviewer 拓扑、
Blueprint hash 或重复 CI job 重新实现为项目脚本。

真实供应商额度由供应商端配置管理。任何会接触生产、凭据或外部状态的工具仍必须属于
一次明确授权的任务；脚本存在或某个环境变量被设置，本身都不构成授权。
