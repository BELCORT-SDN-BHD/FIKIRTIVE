## Helper API (`apps/web/lib/otto-mentions.ts`)

```ts
activeMentionQuery(text: string, caret: number): string | null
```
Returns the query string after `@` if there is an active in-progress mention at the caret, `null` otherwise. Rules: `@` must be at position 0 or preceded by whitespace (email-style mid-word `@` excluded); space between `@` and caret closes the mention (returns `null`).

```ts
resolveSentEntityIds(text: string, picked: { id: string; name: string }[]): string[]
```
Returns only the ids from `picked` whose `@name` still appears in `text` (case-insensitive). Re-validates at send time so deleted mentions don't leak their binding.

## Popover keyboard model

- Popover shows when `mentionSuggestions.length > 0` (derived: `entities` filtered by `mentionQuery`, capped at 6)
- `↑/↓` move `mentionHighlight`, clamped to `[0, suggestions.length - 1]`
- `Enter` or `Tab` → `selectMention(suggestions[mentionHighlight])`, `preventDefault`, no submit
- `Escape` → `setMentionQuery(null)` + `setMentionHighlight(0)`, `preventDefault`
- Enter submits (existing behavior) only when popover is closed

`selectMention`: replaces `@query` (from `lastIndexOf("@")` to caret) with `@<entity.name> `, dedupes `pickedMentions` by id, closes popover, refocuses textarea via `setTimeout`.

## entityIds flow to the route

1. User types `@Sunglasses` → gets completed to `@Sunglasses ` → `{id:"e1",name:"Sunglasses"}` added to `pickedMentions`
2. On `submit()`: `resolveSentEntityIds(trimmed, pickedMentions)` → `["e1"]` (re-validates against final text)
3. Passed as `{ body: { projectId, threadId, entityIds: ["e1"] } }` to `sendMessage`
4. `prepareSendMessagesRequest` forwards `body.entityIds` into the JSON body sent to `POST /api/otto/stream`
5. Route already accepts `entityIds` at line ~81 and attaches it to the user message payload at line ~156
