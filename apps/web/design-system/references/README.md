这里保存被取代的设计包和退役资产，目的只是在需要追溯历史决定时有证据。任何新组件、页面或
验收都不能引用这里作为现行规则。

- `legacy-v3/`：2026-07-07 v3 规则与 guideline cards，已被 Founder 2026-08-20 的 v4 方向取代。
- `retired-assets/`：旧 runtime copies 与机器人/渐变 identity assets，不再发布或消费。

旧文档路径可能通过 symlink 继续可读，那只是为了不让历史链接失效，不会恢复它们的 authority。
