# Library reference mapping

> 本文件只记录 interaction / layout evidence；Fikirtive taxonomy 与 ownership 仍由 information architecture 决定。

## Generation history

- [Midjourney — Organize flow](https://mobbin.com/flows/8bc6fc76-95e5-455f-bc2a-ea19ebea440c)
  - Use: high-density chronological browsing without permanent card chrome.
- [Midjourney — Filtering images](https://mobbin.com/flows/9f289e97-3a07-4f88-b087-240a52077952)
  - Use: filters remain secondary to the media grid.
- [Luma AI — Ideas library](https://mobbin.com/screens/9e14fff0-3b96-4b93-80ab-cc989c187287)
  - Use: light media-type filtering and favorites layered over a generation surface.
- [Runway — Assets](https://mobbin.com/screens/61e28da2-5580-4931-b9f5-a2ca15b6d16e)
  - Use: separate all generations, private uploads, shared, favorites and folders while keeping one asset system.
- [Gamma — All images](https://mobbin.com/screens/ea5bdec6-99a5-4786-8657-1d2712d0422d)
  - Use: selection mode produces a contextual bottom bar instead of filling every card with actions.

## Asset detail

- [Leonardo AI — Generation detail](https://mobbin.com/screens/432b8df4-ca40-4aed-8b85-44c6bdfeae17)
  - Use: preview dominates; prompt, model and reuse actions live in a restrained detail rail.
- [Magnific — Image detail](https://mobbin.com/screens/fb00d495-1bfd-4e02-9386-bff519ce9e16)
  - Use: prompt, settings and reference provenance remain attached to the media.
- [ElevenLabs — Image detail](https://mobbin.com/screens/dbe81af1-959b-4b31-ac59-80ec20df73bb)
  - Use: direct actions such as reference, recreate and image-to-video are available from a focused detail surface.
- [Visual Electric — Image detail](https://mobbin.com/screens/05d3c06e-f343-42cc-8ec4-124b69eda8a3)
  - Use: selected media can return to the creation canvas without becoming a separate editing product.

## Collections and uploads

- [Midjourney — Creating a smart folder](https://mobbin.com/flows/7301a6b5-5520-44fb-97b3-a6a023977008)
  - Rejected for v1: automated smart-folder rules add setup and another taxonomy. Fikirtive adopts only the visible separation between browsing and organization.
- [Canva — Uploading an image](https://mobbin.com/flows/787a0f7a-bb20-43fb-a79e-08bbc61675fa)
  - Use: upload appears in the reusable media surface and can immediately be placed in active work.

## Official avatars

- [Synthesia — Avatar catalog and preview](https://mobbin.com/screens/c9da7197-d8d8-45a2-a206-fdf85be82067)
  - Use: catalog browsing stays separate from a focused preview and `Use` action.
- [Synthesia — Creating a video](https://mobbin.com/flows/218f3b7c-e6de-444e-bbd1-3879d1f49370)
  - Use: selecting an official avatar is an input to creation, not an ownership transfer or identity edit.
- [VEED — Adding an AI avatar video](https://mobbin.com/flows/32e74574-8857-42b6-b3a3-3212cad14ed4)
  - Use: avatar choice, language and script are creation settings; Fikirtive keeps those in Canvas rather than bloating the Library catalog.
