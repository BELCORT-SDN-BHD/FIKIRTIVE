# Founder Home reference mapping

## Application shell

- [Cloudflare account home with docked Ask AI](https://mobbin.com/screens/26e17ee1-b1cf-4c16-8fdf-d385b5045c2f)
  - Use: fixed rail, thin utility bar, docked assistant, main content shrinks instead of being covered.

## Normal analytics state

- [Shopify analytics dashboard](https://mobbin.com/flows/99695c33-c6c9-4a93-98a8-e1b1b0d69bf4)
  - Use: shared date comparison and governed metric cards.
- [Midday reports dashboard customization](https://mobbin.com/flows/189de450-9044-446f-8a7b-8a6951473be5)
  - Use: calm analytical canvas and edit controls that disappear outside customize mode.

## Customize Home

- [Shopify reorder metric cards](https://mobbin.com/flows/680fd7cd-4429-4f23-b68d-6443333b3157)
  - Use: metrics library, explicit unsaved state, drag ordering, `Cancel` and `Save`.
- [Base44 customize dashboard](https://mobbin.com/flows/78d62466-4a70-4725-8ae7-98258663e14f)
  - Use: lightweight right-side selection panel.
- [Calendly customize dashboard](https://mobbin.com/flows/0e64f9f8-30e5-40c5-af98-66a76e0f8393)
  - Rejected as the primary pattern: its modal interrupts the relationship between library and canvas.
- [Whop editing widgets](https://mobbin.com/flows/2003fab6-ccaa-4824-bf06-3d47d28a5afc)
  - Rejected as the primary pattern: its freedom is closer to a dashboard builder than a founder Home.

## Goal templates

- [Google Analytics Reports snapshot](https://support.google.com/analytics/answer/10668965?hl=en_U)
  - Use: begin with a business-goal template, then allow governed card customization.
