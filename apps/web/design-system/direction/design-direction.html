01 · 总构图

三层一次看清

LAYER 1
品牌

FIKIRTIVE Brandkit(传统 agency 式)

一套名字、一枚 F 标、一朵 Otto 云、一张色板、一副字体、一种说话方式。管住所有触点:favicon、登录页、邮件、分享卡、法务页——今天这些地方是「一个名字三种写法、一个吉祥物四套长相、favicon 还是框架默认」。

LAYER 2
外壳

SaaS Dashboard(七扇门不变,皮全换)

浅色分组侧栏 + 白卡内容区 + 大标题面包屑 + 黑色主按钮 + 渐变糖点缀。信息架构沿用换壳 V1 已拍板的七门(Home / Create / Library / Brand / Campaigns / Schedule / Settings),Otto 以右下角弹出按钮出场(Sidekick 式)。

LAYER 3
画布

Canvas Section(Stitch 式整页工作区)

点 Create 进画布 = 离开 dashboard,整页归画布。浮动 Otto 气泡讲人话,左下 agent log 排队留痕,底部一个输入框统一全部创作起手。现有引擎(钱路纪律、血缘、@实体引用)原样保留,只换组织方式和皮。

Stitch 十条语法 → FIKIRTIVE 采纳表

Stitch 的招采纳落到 FIKIRTIVE
整页无限画布采纳现有 FlowCanvas 已是整页,换皮 + 补「视角记忆」(今天每次刷新都重置缩放)
浮动对话气泡采纳取代第三个输入框;Otto 在画布内按 project 分席对话
Agent log 任务队列采纳排队、单条取消、全留痕——对上产品原则「有迹可循」;排队机制接现有 GenJob
底部唯一输入框采纳三框合一:画布 composer、Otto 聊天、编辑 prompt 收成一个 omnibox(治「三套心智模型」病)
先出计划再生成采纳多资产任务先出清单让商家确认——与现有「花钱先批准」天然同构
变体不覆盖原稿已有「More like this」+ 血缘树已是这个逻辑,皮上把「从这张长出来」画得更明白
选中即寻址(单选/多选/全局)已有已有单卡工具条 + 多选批量条,保留;补齐「按对话筛选」(代码里有但死了)
$0 直接编辑已有便签、裁剪、拖放上传本就免费——Stitch 被骂最狠的坑我们先天没有
双索引历史(线程↔画布互相高亮)采纳ChatThread 与卡片的关联字段已在库里,差的只是这层 UI
连线做原型 / Play 模式不做那是 UI 设计工具的需求;营销素材不需要——顺手摘掉卡片上残留的连线把手
先天补掉 Stitch 的两个大坑:① 它曾经「改一个字也要跑一轮 AI」,被骂到后来加免费直接编辑——我们的 $0 路径(便签/裁剪/上传/排列)从第一天就在;② 它每张图各画各的、风格漂移——我们的 @实体引用 + 品牌记忆本来就是「同一个角色/产品长一个样」的机制,这正是我们比它强的地方,皮上要把这优势演出来。
06 · Otto 出场方式

一个 Otto,两种在场

  • Dashboard 里:右下角珊瑚圆钮(Sidekick 式),点开弹出面板;全局会话,跨页跟随。
  • 画布里:浮动气泡 + agent log,按 project 分席——每张画布自己的对话史,不与外面串线。
  • 两边共享一个 knowledge base:商家是谁、品牌记忆、生意事实两边都记得;Otto 自行判断何时更新知识库(Founder 8/20 提议,连接前后端时展开,已入档不丢)。
  • 珊瑚 = Otto 在场(若选方向 A/C):画布上任何 AI 正在动的东西,都以珊瑚示意——进度环、气泡描边、生成中的卡片呼吸灯。
07 · Brandkit 骨架 · 待你 elaborate

传统 agency 式 brandkit 章节表(草案)

按你的定义:general 层,不含 components。以下九章是 agency 标配,哪些砍、哪些加重,等你 elaborate 时逐条定。

1 · Logo 系统

F 标正稿 + 横版 wordmark + 最小尺寸/留白/误用示例。治「一个名字三种写法」。

2 · Otto 吉祥物规范

云朵官方几何 + 8 表情 + 使用场景(哪里能出现、多大、能不能开玩笑)。治「四套长相」。

3 · 色彩

主色/中性灰阶/渐变糖/语义色,含无障碍对比度底线。

4 · 字体

品牌字 + 数据字(等宽),层级样例。

5 · 声音与语气

Otto 怎么说话、产品怎么报错、空态怎么写——「诚实」已是产品法,这里给它一个声音。

6 · 渐变与影像语言

渐变怎么用不俗、截图/插画风格、AI 生成物在品牌语境里怎么呈现。

7 · 应用示例

favicon、浏览器标签、登录页、邮件、社交分享卡(OG)、pitch deck 封面——全是盘点里查出的空白。

8 · 动效性格

节奏与缓动的性格定义(快而轻 vs 稳而柔),给 prototype 场做底。
